# 使用指南

[返回项目首页](../README.md) · [开发文档](development.md) · [更新日志](../CHANGELOG.md)

本文对应 Pi Desktop v0.7.3。界面示例见 [浅色工作台](screenshots/workbench-light.png)、[深色工作台](screenshots/workbench-dark.png) 和 [外观设置](screenshots/appearance-settings.png)；示例截图保留自 v0.3.0。

## 安装与启动

从 [GitHub Releases](https://github.com/facron2004/pi-desktop/releases/latest) 下载适合设备架构的 Windows 安装包，或下载 x64 免安装 ZIP，解压后运行 `Pi Desktop.exe`。

发布包已包含 Electron 与 Pi CLI，运行桌面版不需要另外安装 Node.js。模型调用仍需要可用的供应商认证。

设置与会话保存在本机。升级沿用现有数据，无需手工迁移；免安装版表示无需安装程序，其配置并不随 ZIP 自动搬移到另一台电脑。

## 模型与认证

在「设置 → 模型管理」按提供商配置连接：

1. 点击「添加提供商」，填写名称、接口格式、Base URL 和 API Key。
2. 点击「获取模型列表」。上游返回的全部模型会带上上下文长度、最大输出、推理能力、图片支持与价格；也可以手动添加模型。
3. 右侧开关决定该模型是否进入模型选择。左侧箭头展开具体配置，可修改上游没给全的参数。只有打开开关的模型会写入 Pi；关掉的模型仍留在本机，下次还能再打开。
4. 上游缺失的参数在精确匹配 Pi 目录时标为「Pi 目录参考」，其他缺失项留空，可手动补充。目录价格不会套用到自定义提供商。
5. 点击「检测连通性」。未选择模型时检测模型列表接口；选择后发起最小模型请求验证推理调用。
6. 点击「保存并使用」。当前空闲会话会刷新 Pi 模型配置并切换到默认模型；其他会话保留自己的模型，正在运行的对话保持运行，新配置用于新对话。

配置沿用 Pi 原生的 `models.json`。只有启用的模型会写进去，因此才会出现在模型选择中；关掉的模型留在同目录的 `models.desktop.json`。API Key 保存在本机；点击提供商右侧的编辑图标修改，重新编辑时不会回传已保存的密钥，留空保留原值。删除图标经确认后移除该提供商的模型配置与 API Key，保留其他提供商和 Pi 登录。

已有的 Pi 登录和扩展认证仍由 Pi 管理：

- 已使用 Pi 的用户可以复用现有登录或配置。
- 如果已安装独立 Pi CLI，可运行 `pi`，输入 `/login` 并按提示完成供应商登录或 API Key 配置。
- 也可以按照 [Pi 供应商文档](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/providers.md) 配置环境变量或其他认证方式。
- 返回应用，在「设置 → 模型管理」编辑对应提供商并选择模型。对话中的模型和推理强度控件可调整当前会话。

模型价格、上下文长度与推理选项以 Pi 返回的内容为准。请勿把 `auth.json`、API Key 或包含凭证的日志提交到仓库。

## 权限与任务模式

输入框添加按钮旁提供「请求批准」「帮我批准」「完全访问」三档权限。默认请求批准；帮我批准只自动通过工作目录内的常规文件读写，命令、目录外访问、敏感路径和未知工具仍需确认。完全访问不再逐次请求工具批准。

添加菜单提供普通、目标、计划和子代理四种任务模式，也可以直接用 `/plan`、`/goal`、`/subagent` 切换。目标模式持续推进目标直至完成或受阻，目标条可暂停、恢复、编辑或清除；计划模式只使用只读工具探索，完成后通过 `exit_plan_mode` 请用户批准；普通模式也可以直接使用子代理工具，子代理模式会进一步要求优先委托；子代理在隔离上下文中执行独立任务。模式状态保存在 Pi 会话中。

启动子代理后，右侧工具面板的「Subagents」页会出现紧凑的目录树，按所属会话和任务分层显示。每行左侧是状态与名称，中间是当前活动，右侧是 token 用量与耗时；点击任务进入该子代理的会话，查看完整对话、工具调用和输出，点「Back」返回目录；点击会话名返回对应聊天。切换聊天不会隐藏后台任务，重新打开已保存会话也能查看子代理结果。

## 项目与会话

打开项目后，Pi 在该目录下工作。侧栏的项目行用于展开与收起会话；项目选择器、文件夹入口和 `Ctrl+1…9` 才会主动切换项目。

项目可以戴一个表情图标：在项目行左侧点图标，会打开选择器，可搜索表情（支持中英文关键词）并挑选一种颜色；图标和颜色跟随项目保存。点项目行的其余部分仍然只是展开或收起会话列表。项目行右侧的数字是该项目的会话数，鼠标移到行上时会让位给操作按钮。

会话行左侧的标记说明这条会话发生了什么：蓝点表示它在后台跑完、你还没看过；红点表示上一次运行失败；「等待输入」标签表示 Pi 卡在一个需要你回答的对话框上。打开该会话后标记消失，正在看的会话不显示标记。

历史会话支持重命名、置顶、搜索和 HTML 导出。切换项目、打开历史会话和跳转搜索结果只更换当前视图，后台任务继续执行；输入框的停止按钮只停止当前会话，也可从侧栏停止指定会话。

不同工作目录的会话可以同时执行，同一目录的任务按队列执行，避免同时修改同一批文件。同项目需要并行执行时，可使用独立的 Git worktree。目录有任务运行时，Git 切分支、回滚、应用补丁等写操作会提示等待；正在进行的 Git 写操作也会让新任务等待。

应用启动时恢复上次项目并进入新聊天，不自动续接上次会话。点击历史会话才会打开它。

悬停用户消息会显示时间、复制和编辑图标。编辑复用 Pi 的分支能力：从该消息之前创建新会话，保留更早历史，并把原文放回输入框，修改后再发送。

会话树可查看各分支与消息路径，从用户消息处创建分支；复制会话则复制当前分支到新会话。

## 任务栏

对话右侧的任务栏用四段回答当前会话的状态，标题可折叠：

- **环境信息**：标题下是所在分支；「变更」一行右侧是本次改动的增删行数，点击打开变更面板，「提交或推送」打开提交对话框，右侧小按钮直接推送，「变更图谱」打开提交历史。
- **后台任务**：本轮启动的子代理任务，右侧圆点表示进行中、已完成或失败。
- **进度**：助手回复里的 Markdown 清单，右侧显示已完成步数；完成的步骤是实心圆点并加删除线。
- **交付物**：本次运行写下的文件，按目录折叠成树，点文件名在右侧面板打开。

任务栏默认展开，可用标题栏的清单按钮收起。

## 对话与工具过程

助手内容采用连续文档排版。连续的工具操作汇总为一行活动摘要，思考、参数、结果与差异可按需展开。失败工具默认展开，停止和未执行分别显示，不会被当作成功。

工作中，发送按钮在没有草稿时用于停止；输入新内容后可继续引导任务或排队发送，停止入口出现在输入区域下方。

`@` 用于查找并引用项目文件，`/` 用于查找 Pi 与桌面应用命令。桌面命令包括 `/export`、`/duplicate`、`/branch`、`/compact`、`/copy`、`/changes`、`/files` 和 `/new`。

当 Pi 扩展发起选择、确认、输入或编辑请求时，应用会显示对应对话框。回答后，Pi 才能继续执行。

## 文件、Git 与终端

右侧工具面板按浏览器的标签组织：顶部是本次打开的页面及其关闭按钮，「+」打开工具导航页；Files、File changes、Subagents、Terminal、Browser、Images、Tasks 都是导航入口，打开后成为一个可切换的页面标签。

| 工具 | 用法 |
| --- | --- |
| 文件 | 按路径查找文件或搜索文本，查看语法高亮、行号和图片。查看器支持查找、跳转行号、换行及复制。 |
| Git 更改 | 查看工作区与逐文件差异、暂存与取消暂存、提交历史、文件和 hunk 回退。回退需要确认；未跟踪文件不会被直接删除。 |
| 分支 | 切换分支、新建分支、创建 worktree，并把 worktree 作为项目打开。 |
| 终端 | 在当前项目打开真实终端（PowerShell / CMD / Git Bash / WSL 可在设置中切换），支持提示符、交互命令、滚动缓冲、复制、清屏与重启。 |
| 网页与图片 | 在工具面板查看网页和项目图片，保持与会话并排。 |
| 任务 | 从助手回复中的 Markdown 清单提取步骤，与对话中的计划条保持一致。 |

提交时，如果已有暂存内容，默认只提交暂存部分；勾选包含未暂存更改后才会先暂存整个工作区。不是 Git 仓库的文件夹也可以正常作为项目使用。

## 设置

| 分区 | 内容 |
| --- | --- |
| 常规 | 语言、项目外聊天目录、默认编辑器及常用操作偏好。 |
| 模型管理 | 按提供商填写连接、拉取模型和参数、检测连通性、选择默认模型与推理强度。 |
| 外观 | 深浅主题、可搜索的系统字体、苹方字重、字号、强调色、背景及差异颜色。 |
| 用量 | 从本地会话汇总今日、本周、本月、累计及模型维度的 Token 与费用。 |
| 插件 | 查看 MCP、项目扩展与技能命令。MCP 视图不建立连接，只显示配置。 |
| 个性化 | 为 Pi 提供自定义指令。 |
| 面板 | 面板尺寸与差异显示方式。 |
| 项目安全 | 是否允许加载项目本地配置与扩展。 |
| 关于 | 应用及 Pi 版本信息和检查入口。 |

MCP 只展示环境变量和请求头的键名，不展示凭证值。用量来自本地历史记录，不代替供应商账单。
