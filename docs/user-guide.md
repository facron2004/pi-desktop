## 安装与启动

从 [GitHub Releases](https://github.com/facron2004/pi-desktop/releases/latest) 下载适合设备架构的 Windows 安装包，或下载 x64 免安装 ZIP，解压后运行 `Pi Desktop.exe`。

发布包已包含 Electron 与 Pi CLI，运行桌面版不需要另外安装 Node.js。模型调用仍需要可用的供应商认证。

设置与会话保存在本机。升级沿用现有数据，无需手工迁移；免安装版表示无需安装程序，其配置并不随 ZIP 自动搬移到另一台电脑。

## 模型与认证

在「设置 → 模型管理」按提供商配置连接：

1. 点击「添加提供商」，填写名称、接口格式、Base URL 和 API Key。
2. 点击「获取模型列表」。上游返回的全部模型会带上上下文长度、最大输出、推理能力、图片支持与价格；也可以手动添加模型。
3. 右侧开关决定该模型是否进入模型选择。左侧箭头展开具体配置，可修改上游没给全的参数。只有打开开关的模型会写入 Pi；关掉的模型仍留在本机，下次还能再打开。
4. 上游缺失的参数在精确匹配 Pi 目录时标为「Pi 目录参考」，其他缺失项留空，可手动补充。目录价格不会套用到自定义提供商。
5. 点击「检测连通性」。未选择模型时检测模型列表接口；选择后发起最小模型请求验证推理调用。
6. 点击「保存并使用」。当前空闲会话会刷新 Pi 模型配置并切换到默认模型；其他会话保留自己的模型，正在运行的对话保持运行，新配置用于新对话。

配置沿用 Pi 原生的 `models.json`。只有启用的模型会写进去，因此才会出现在模型选择中；关掉的模型留在同目录的 `models.desktop.json`。API Key 保存在本机；点击提供商右侧的编辑图标修改，重新编辑时不会回传已保存的密钥，留空保留原值。删除图标经确认后移除该提供商的模型配置与 API Key，保留其他提供商和 Pi 登录。

已有的 Pi 登录和扩展认证仍由 Pi 管理：

- 已使用 Pi 的用户可以复用现有登录或配置。
- 如果已安装独立 Pi CLI，可运行 `pi`，输入 `/login` 并按提示完成供应商登录或 API Key 配置。
- 也可以按照 [Pi 供应商文档](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/providers.md) 配置环境变量或其他认证方式。
- 返回应用，在「设置 → 模型管理」编辑对应提供商并选择模型。对话中的模型和推理强度控件可调整当前会话。

模型价格、上下文长度与推理选项以 Pi 返回的内容为准。请勿把 `auth.json`、API Key 或包含凭证的日志提交到仓库。

## 权限与任务模式

输入框添加按钮旁提供「请求批准」「帮我批准」「完全访问」三档权限。默认请求批准；帮我批准只自动通过工作目录内的常规文件读写，命令、目录外访问、敏感路径和未知工具仍需确认。完全访问不再逐次请求工具批准。

添加菜单与斜杠命令提供四种工作模式：**默认、目标、蜂群、插件**；另有**计划模式**，它是一种只读探索的审批门。

- **目标模式**（`/goal`）持续推进目标直至完成或受阻。输入框上方的目标条显示状态、运行时长与阻塞原因，可暂停、恢复、编辑或清除，详情浮层从上方展开。
- **蜂群模式**（`/swarm`）由主会话带领一组常驻工作者：可以派出、指派任务、互通消息、收集结果并解散；右侧工具面板的「蜂群」页实时显示每个工作者的状态、当前任务与输出，可单独或全部停止。
- **插件模式**（`/plugin`）保持常规工具集，并要求智能体产出一个 Pi 扩展（写出文件、用一次性 `pi -e` 做加载检查、报告路径）。
- **计划模式**（`/plan`）只使用只读工具探索，并禁止委派；写完计划后在对话中审阅，可以「继续规划」或明确批准，批准前不放开写入工具。

**子智能体是一个工具，不是模式**：除计划模式外，各工作模式都带 `subagent` 工具，遇到可独立完成的任务时直接委派，不必先切换模式。子智能体在隔离上下文中执行任务，可以指定模型、推理强度、工具与超时；每个子任务的进度、token 与耗时都显示在工具卡片里。

模式状态保存在 Pi 会话中；已保存的旧「子智能体模式」会话重新打开时回到默认模式。

模型遇到需要你决定的问题时，可以弹出单选问答框。选择后点「发送」即可继续当前会话。取消会结束这次等待，你可以在输入框继续说明。计划模式的方案审阅仍在对话与审阅框中进行。

启动子智能体后，右侧工具面板的「Subagents」页会出现紧凑的目录树，按所属会话和任务分层显示。每行左侧是状态与名称，中间是当前活动，右侧是 token 用量与耗时；点击任务进入该子智能体的会话，查看完整对话、工具调用和输出，点「Back」返回目录；点击会话名返回对应聊天。切换聊天后，子智能体仍会在目录中更新，重新打开已保存会话也能查看结果。标题栏会话名旁的徽标显示委派数量与运行中状态，点开可查看每个子任务并跳到它的对话。

## 项目与会话

打开项目后，Pi 在该目录下工作。侧栏的项目行用于展开与收起会话；项目选择器、文件夹入口和 `Ctrl+1…9` 才会主动切换项目。

项目可以戴一个表情图标：在项目行左侧点图标，会打开选择器，可搜索表情（支持中英文关键词）并挑选一种颜色；图标和颜色跟随项目保存。点项目行的其余部分仍然只是展开或收起会话列表。项目行右侧不显示会话数，鼠标移到行上时出现操作按钮。

会话行左侧的标记说明这条会话发生了什么：蓝点表示它在后台跑完、你还没看过；红点表示上一次运行失败；「等待输入」标签表示 Pi 卡在一个需要你回答的对话框上。打开该会话后标记消失，正在看的会话不显示标记。

历史会话支持重命名、置顶、搜索、归档和 HTML 导出。被归档的会话在单列表模式下按项目分组折叠在列表底部。切换项目、打开历史会话和跳转搜索结果只更换当前视图，后台任务继续执行；输入框的停止按钮只停止当前会话，也可从侧栏停止指定会话。

不同工作目录的会话可以同时执行，同一目录的任务按队列执行，避免同时修改同一批文件。同项目需要并行执行时，可使用独立的 Git worktree。目录有任务运行时，Git 切分支、回滚、应用补丁等写操作会提示等待；正在进行的 Git 写操作也会让新任务等待。

应用启动时恢复上次项目并进入新聊天，不自动续接上次会话。点击历史会话才会打开它。

悬停用户消息会显示时间、复制和编辑图标。编辑会在当前会话的会话树内回退到该消息之前（不是新建会话），保留更早历史，并把原文放回输入框，修改后再发送；旧分支仍保存在会话树中。

会话树可查看各分支与消息路径，从用户消息处创建分支；复制会话则复制当前分支到新会话。

## 任务栏

对话右侧的任务栏用五段回答当前会话的状态，标题可折叠：

- **环境信息**：标题下是所在分支；「变更」一行右侧是本次改动的增删行数，点击打开变更面板，「提交或推送」打开提交对话框，右侧小按钮直接推送，「变更图谱」打开提交历史。
- **后台任务**：显示当前会话中 Pi 已启动且仍在运行的 Shell 命令，例如 `npm run build`。持续两秒后显示，结束即移除。
- **子智能体**：显示当前会话最近委派的任务，行首图标按排队 / 运行 / 完成 / 失败着色。点击任务名即可查看实时进展和结果。
- **进度**：智能体用 `desktop_todo` 工具记下的清单；如果从未用过该工具，则取最新一条带清单的助手回复（少于两项的清单忽略）。右侧显示已完成步数，完成的步骤是实心圆点并加删除线。
- **交付物**：本次运行写下的文件，按运行触碰的顺序列成一行一个文件（同名文件才会标出所在目录），点文件名在右侧面板打开，悬停可看完整路径。

任务栏默认展开，可用标题栏的清单按钮收起。

## 对话与工具过程

助手内容采用连续文档排版。连续的工具操作汇总为一行活动摘要，思考、参数、结果与差异可按需展开。失败工具默认展开，停止和未执行分别显示，不会被当作成功。

工作中，发送按钮在没有草稿时用于停止；输入新内容后可继续引导任务或排队发送，停止入口出现在输入区域下方。

`@` 用于查找并引用项目文件，`/` 用于查找 Pi 与桌面应用命令。桌面命令包括：`/name`、`/plan`、`/goal`、`/swarm`、`/plugin`、`/image`、`/export`、`/duplicate`、`/branch`、`/tree`、`/mcp`、`/compact`、`/copy`、`/changes`、`/commit`、`/terminal`、`/files` 与 `/new`。命令也可以输入中文别名（如 `/计划`、`/目标`、`/图片`）。

当 Pi 扩展发起选择、确认、输入或编辑请求时，应用会显示对应对话框。回答后，Pi 才能继续执行。

### 图片生成

`/image`（或添加菜单的「图片」）会把模型、尺寸、质量与数量控件加载到输入框上方；提示词就是一条普通用户消息，生成结果以卡片形式出现在回复下方，可直接「设为参考图」、在文件管理器中定位或复用提示词。计划模式下该次调用自动放行，不再弹确认。

### 定时任务

侧栏顶部、新建对话下方的「定时任务」打开一个独立页面（不是设置对话框）：左侧是任务列表，右侧是所选任务的规则、运行记录与操作。任务有自己的项目、提示词、计划（一次性、每天或每周）、模型与推理强度；留空表示跟随应用默认值。任务运行中可在右侧直接停止本次运行（保留原计划），删除任务会在详情区就地确认；损坏的任务文件会被改名留档并从空列表继续，而不是让页面永远空白。

### 插件与技能

侧栏顶部、新建对话下方的「插件与技能」打开 Pi 官方包目录（pi.dev/packages）：可搜索、翻页、按下载量排序浏览（卡片显示每月下载量），安装过程实时显示进度。页面内也能查看 MCP 配置、项目扩展与技能命令——MCP 视图只显示配置，不建立连接，也不显示凭证值。项目本地配置与扩展是否加载由「设置 → 常规 → 项目安全」控制。

## 文件、Git 与终端

右侧工作区面板与 MCode 对齐：顶部是固定宽度的页面标签（悬停显示关闭按钮，可拖动排序、右键关闭其他/右侧/全部），「+」打开尚未打开的页面的菜单；关闭全部页面后显示「从这里开始」的入口卡片。面板可最大化到工作区大小；Files 与 File changes 采用右侧文件树的左右分栏，预览或差异不会再把文件树挤走。

| 工具 | 用法 |
| --- | --- |
| 文件 | 按路径查找文件或搜索文本，查看语法高亮、行号和图片。查看器支持查找、跳转行号、换行及复制。 |
| Git 更改 | 查看工作区与逐文件差异、暂存与取消暂存、提交历史、文件和 hunk 回退。回退需要确认；未跟踪文件不会被直接删除。 |
| 分支 | 切换分支、新建分支、创建 worktree，并把 worktree 作为项目打开。 |
| 子智能体 | 按会话与任务分层显示所有子智能体；点任务查看完整对话与输出，可停止排队或运行中的任务。 |
| 蜂群 | 显示蜂群模式中每个工作者的状态、当前任务与输出，可单独或全部停止。 |
| 终端 | 在当前项目打开真实终端（PowerShell / CMD / Git Bash / WSL 可在设置中切换），支持提示符、交互命令、滚动缓冲、复制、清屏与重启；标签记住创建时的目录。 |
| 网页与图片 | 在工具面板查看网页和项目图片，保持与会话并排。 |

提交时，如果已有暂存内容，默认只提交暂存部分；勾选包含未暂存更改后才会先暂存整个工作区。不是 Git 仓库的文件夹也可以正常作为项目使用。

### 手机远程访问

在「设置 → 远程访问」开启服务，用手机相机扫描配对二维码；二维码三分钟后过期且只能使用一次。手机浏览器打开链接后点「连接」，即可选择已登记的项目和已有对话，查看最近记录与实时更新并发送消息；运行中的对话可以直接停止，Pi 弹出的选择、确认、输入对话框也能直接在手机上回答，无需回到桌面。在会话列表可以发起新对话——第一条消息发出后新会话即出现在项目里。桌面端可随时撤销某部手机的连接。

该连接只适用于同一可信 Wi-Fi 网络，HTTP 流量未加密；请勿在公共网络中开启。手机发送的消息沿用 Pi Desktop 当前的智能体权限设置，需要批准的操作仍须在桌面端确认。

### IM 频道

在「设置 → IM 频道」把飞书或微信接入 Pi 对话。每条频道绑定一个已登记项目中的一个对话：在 IM 里发消息即向该对话发送指令，任务完成后 Pi 会把最终回答推送回来；Pi 需要确认时也会主动提醒（确认仍需在桌面或手机远程页完成）。

**飞书**：在飞书开放平台创建自建应用 → 开启机器人能力 → 订阅 `im.message.receive_v1` 事件并选择「长连接」模式 → 开通 `im:message` 与 `im:message:send_as_bot` 权限 → 发布版本。把 App ID 和 App Secret 填进设置页即可，长连接不需要公网 IP 或域名。可用「允许的会话 ID」限制机器人只在指定群聊或私聊中响应。

**微信**：Pi Desktop 不注入微信进程。先自行运行开源桥接服务 wechatbot-webhook（`npx wechatbot-webhook`，微信扫码登录），再把设置页显示的回调地址填入桥接服务的 `RECVD_MSG_API` 环境变量，并填入桥接服务显示的个人令牌。请注意：web 微信协议由第三方开源项目实现，存在账号限制风险，请自行评估。

频道绑定后，IM 里可用命令：`/help` 查看命令、`/status` 查看绑定对话状态、`/stop` 停止当前运行、`/new` 切换到新对话（绑定随之更新）。普通消息按顺序驱动对话，回答通过原频道返回。
