# Pi Desktop v0.11.7

## 更新内容

- **蜂群模式**。新增蜂群任务模式：主持会话可以组建一组有名字的常驻工作者，跨轮次持续协作，不必每轮重新交代上下文。右侧工具面板新增「蜂群」页，实时显示每个工作者的状态、当前任务、活动与输出，可单独停止某个工作者或全部停止。工具卡片按创建、指派、留言、收集、解散分别命名。
- **提问与计划评审**。Agent 可以用 `desktop_ask_user` 提出 2–5 个选项的问题并等待选择；问题与最终选择都保留在对话记录中，未选择时会明确标注，展开卡片还能看到当时有哪些备选。计划模式改为评审流程：计划正文在对话框中阅读，可以选择「继续规划」或明确批准执行，批准之前写入类工具不会放开。
- **目标模式与思考过程**。自动续跑增加了轮次上限与空转检测——连续没有进展就暂停并说明原因，而不是无限重试。每一轮独立计时并在对话里留下轮次分隔，目标条支持暂停 / 恢复 / 完成 / 清除，并新增目标详情弹层。进程退出后目标显示为「未激活」并保留恢复入口。Pi 返回的思考文本按轮折叠成一行「思考内容」，默认收起、展开后才挂载正文；被提供商隐藏的思考与签名不会进入对话。
- **过程与状态呈现**。工具调用改为内联分组（图标 + 动词 + 计数），失败原因固定显示在运行摘要下方，即使把过程折叠也能看到。运行摘要能显示「准备请求」与「等待模型响应」（超过十秒改为「仍在等待」），并与耗时共用同一行。
- **工作区文件工具**。内置 `grep` / `find` / `ls`（Windows 另有 `powershell`）默认可用，并为模型补充对应的使用指引与 Windows 路径、glob 归一化，减少在 Windows 上因为分隔符和通配符写法失败的搜索。
- **通知、托盘与更新**。桌面通知正文带上回复首句，可以直接在通知里内联回复并打开对应会话，中英文按界面语言显示。托盘弹窗在图标被收进系统溢出区时按指针位置弹出，并在页面首帧绘制完成后才显示。版本检查结果会落盘，离线重启后仍能看到上次发现的版本；静默更新改用 robocopy 拷贝载荷，失败时自动重新启动已安装的旧版本。
- **侧栏与性能**。归档会话可以在原行直接恢复，全文检索遵循归档筛选（在主进程过滤，长会话走索引也保持一致）。悬停卡片的摘除逻辑统一按帧合并，流式输出时不再逐帧强制布局。重开会话时把磁盘历史与已经到达的实时事件合并，既不丢帧也不重复。会话进程停止后撤回它发布的实时读数，蜂群页不会残留「进行中」的工作者。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.7` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
