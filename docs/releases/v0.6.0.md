# Pi Desktop v0.6.0

本版本集中修复多会话的运行隔离、目录排队和退出清理，并包含当前工作区的界面与模型管理改进。内置 Pi coding agent 保持 **1.4.0**。

## 主要更新

- **独立会话**：不同工作目录的会话可同时运行；同一目录的任务排队。浏览项目、切换聊天和搜索跳转只更换视图，后台任务继续执行。
- **操作归属**：消息发送、停止、状态刷新、分叉、供应商切换、工具审批和终端操作始终作用于对应会话；恢复历史沿用该会话自己的模型和推理设置。
- **目录保护**：Git 切分支、回滚、应用补丁和索引写入与后台任务共用目录锁。同项目需要并行执行时，可使用独立 worktree。
- **运行清理**：取消排队任务、直接命令完成、关闭项目及退出应用后正确释放运行占用；先等待 Pi 正常清理，再对超时进程强制结束。
- **流式性能**：正文按会话逐帧合并更新，减少重复刷新；保留既有的提供商参数、字体和输入区域改进。
- **构建范围**：仅打包 main、preload、renderer 程序目录，排除本地截图、浏览器缓存和测试配置。

## 本地构建产物

| 文件 | 用途 |
| --- | --- |
| `Pi-Desktop-0.6.0-x64-setup.exe` | Windows x64 安装版 |
| `Pi-Desktop-0.6.0-arm64-setup.exe` | Windows ARM64 安装版 |
| `Pi-Desktop-0.6.0-portable-x64.exe` | Windows x64 单文件免安装版 |
| `Pi-Desktop-0.6.0-portable-x64.zip` | Windows x64 免安装目录压缩包，解压后运行 `Pi Desktop.exe` |
| `SHA256SUMS.txt` | 产物的 SHA-256 校验值 |

本轮通过类型检查、140 项测试及生产构建。x64 解压程序与单文件免安装版分别通过 33 项实际运行检查，覆盖多会话并行、同目录排队、停止与审批归属和退出清理；两种架构包内的 43 个构建文件均与同一源码快照的构建输出一致。详细结果见产物目录的 `verification.json`。

升级沿用现有本地设置和 Pi 会话，无需迁移。大规模并发容量及真实供应商限流不属于本次包体验证范围；ARM64 包需在 ARM64 设备上进行运行验收。
