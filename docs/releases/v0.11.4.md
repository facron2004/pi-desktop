# Pi Desktop v0.11.4

**发布日期**：2026-11-17  
**内置 Pi**：1.5.2（`@earendil-works/pi-coding-agent`）

---

## 多会话并行体验

- **通知能认出会话**：系统通知以会话名作标题，正文说明是「运行完成」还是「需要你的输入」，点击通知直接打开对应会话；用户主动停止的运行不再发通知。
- **后台完成不再静默**：窗口聚焦时，其他会话完成或失败会弹出带会话名的应用内提示，点击提示即可切换过去；窗口失焦时仍由系统通知承担。
- **排队消息保持可见**：同一目录排队期间，已发送但尚未交给 Pi 的消息以「等待发送」气泡留在对话中，Pi 接收后就地转正；取消排队时文本回到输入框。
- **行内停止**：侧边栏运行中的会话行新增停止按钮（悬停/聚焦显示，触屏常显），无需展开「更多」菜单。
- **排队进度可读**：等待提示追加当前占用会话的已运行时长。
- **修复**：后台会话的临时记录不再借用当前视图的项目路径。

## 对话与工具呈现

- **工具行动作更具体**：工具行按动作与状态显示「正在执行命令 / 读取文件 / 编辑文件 / 写入文件」及失败、停止、未执行等状态，子代理调用直接列出任务名。
- **运行时长兜底**：时间戳无法覆盖整轮时（例如回放数据时钟不齐），改用 Pi 记录在回复与工具上的时长，避免出现没有数字的「已完成」。
- **模型用时去重**：最新一轮的模型时长按带时间戳的样本读取，不再把同一轮的两份记录相加。
- **上下文构成对齐**：分项占比按屏幕上的当前读数缩放，三行之和与标题数字一致。
- **Changes 面板性能**：工具节点的行内 diff 按节点对象缓存，流式输出时不再每帧重建历史 diff 导致窗口卡顿。

## 输入与分支

- **斜杠命令芯片**：输入框把 `/命令` 识别为芯片，命令与参数分开显示，连按两次退格移除。
- **worktree 勾选即生效**：分支菜单底部的 worktree 行改为复选框，勾选只武装下一次会话，真正的目录在该空对话发送首个提示时创建。

## 界面修复

- **弹出层定位**：靠近窗口边缘时自动翻转到空间足够的一侧，并避开原生标题按钮区域；打开菜单时的焦点迁移不再误判为点击外部而立即关闭。
- **面板分隔线**：分隔线贴合面板左缘，拖动方向与面板宽度变化一致。
