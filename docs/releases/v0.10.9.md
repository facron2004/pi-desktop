# Pi Desktop v0.10.9

本版本改进会话目录切换后的历史访问、文件搜索反馈、终端输出管理和后台任务可靠性。

## 改进

- 切换自定义聊天目录后，最近 16 个目录仍可用于列出、搜索、统计、删除和恢复旧会话；新聊天继续写入当前目录。
- 工作区文件列表与搜索现在返回截断状态，让界面明确提示扫描限制可能遗漏结果。
- 终端输出增加序号确认与背压处理，并在窗口销毁或渲染进程退出时清理 PTY。
- 改进 RPC、子 Agent、定时任务、Git、Marketplace、提供商请求和会话管理的可靠性。

## 验证

- `npm run typecheck` 通过。
- `npm run dist` 成功生成 Windows 安装版与解包目录。
- `node scripts/verify-package.cjs` 确认打包应用版本和关键入口。
- 发布安装包与免安装包的 SHA-256 已写入 `SHA256SUMS.txt`。

## 发布文件

- `Pi.Desktop-0.10.9.exe` — Windows x64/ARM64 通用安装包
- `Pi.Desktop-0.10.9-x64.exe` — Windows x64 安装包
- `Pi.Desktop-0.10.9-arm64.exe` — Windows ARM64 安装包
- `Pi.Desktop-0.10.9-portable-x64.zip` — Windows x64 免安装包
- `SHA256SUMS.txt` — 上述文件的 SHA-256 校验值
