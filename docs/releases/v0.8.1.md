# Pi Desktop v0.8.1

本版本加入定时任务、局域网手机远程访问和按项目管理的会话记忆，并更新工作区、会话设置与字体排版。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **定时任务与远程访问**：支持一次性、每天和每周运行任务；可在可信局域网内配对手机、查看项目和会话、发送消息，并随时撤销设备。
- **会话与智能体**：新增可管理的项目记忆、自动生成标题、粘贴图片自动引用；设置可选择默认模型、权限、推理强度和计划模式，并配置子代理模型。
- **工作区与界面**：右侧工具页支持排序和最大化；任务栏、设置、字体与字号进一步对齐 MCode。
- **安全边界**：远程服务默认关闭，手机访问只覆盖项目、会话读取和发送消息；设置页提示局域网 HTTP 未加密。
