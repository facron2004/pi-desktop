# Pi Desktop v0.11.14

## 更新内容

- **检查更新不再弹更新弹窗**。有更新时按原来的逻辑出现在「设置」旁的圆形按钮上——下载进度环、已就绪、重启安装都在那一颗按钮里；**已是最新版本**或**检查失败**时，弹一条只有「知道了」的提示（标题 + 说明 + 当前版本号），不再把一块模态窗口挡在对话前面。从「帮助 → 检查更新」和「设置 → 关于 → 立即检查」触发都是同一套行为。
- **「立即检查」按钮只用文案表示状态**。去掉左侧的转圈图标，两个状态就是「立即检查」和「检查中…」，按钮宽度在切换时不跳。
- **修复「重启并安装」后卡在 100% 无法操作**。原因有两层：那个更新弹窗是全窗口模态，点下安装后组件进入忙碌状态且不允许关闭，只要应用没真正退出，界面就停在「正在重启并安装更新… 100%」并且吞掉所有点击；而重启本身没有上限。现在：
  - 更新弹窗已经移除，不再存在能困住点击的层；
  - 安装器成功启动后，应用 15 秒内必定退出（安装器是独立进程，应用没有理由留着）；
  - 如果重启没有发生（例如安装程序在等系统授权），设置旁的按钮 20 秒后自动回到可重试状态并写明原因，而不是一直转圈。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.14` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
