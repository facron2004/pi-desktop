# Pi Desktop v0.10.3

本补丁版本减少长对话流式更新的重复扫描，并修复特殊文件名可能影响其他 Git 文件的风险。

## 修复

- 长会话按变更位置重建受影响的回合；为会话项建立索引，并复用未变更的历史计数、会话轨道和分支目标。
- Git 的单文件暂存、取消暂存、差异和还原操作使用字面路径，防止带 pathspec 语法的文件名作用于其他文件。
- 高亮缓存限制最多 48 条，并跳过超过 32 Ki 个 UTF-16 代码单元的代码块，避免长文件长期占用过多内存。
- 删除会话时清除对应的工具、文件、过程和历史展开状态。

## 验证

- `npm run typecheck` 通过。
- `npm test`：671 项通过，2 项跳过。
- `npm run dist` 通过；`node scripts/verify-package.cjs` 确认安装包内版本为 0.10.3，主进程、渲染器与远程伴侣文件齐全。
- Windows x64、ARM64、通用安装包和 x64 免安装包已生成，并已计算 SHA-256。
