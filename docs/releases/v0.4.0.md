# Pi Desktop v0.4.0

本次更新集中完善提供商配置、模型参数导入、任务权限与模式，并优化字体和项目交互。内置 Pi coding agent 保持 **1.4.0**。

## 主要更新

- **按提供商管理模型**：使用提供商卡片组织连接，在提供商内部填写 Base URL、API Key，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Gemini。
- **拉取模型并填入参数**：导入上游模型、上下文长度、最大输出、推理能力、图片输入和价格；精确匹配的 Pi 目录参数标明参考来源，缺失项可手动补充，不套用其他提供商的价格。
- **验证连接并保存启用**：检测模型列表接口或发起最小推理请求；保存至 Pi 原生配置，空闲会话可即时刷新，正在运行的对话不会被停止。已有 Pi 登录继续保留。
- **权限与任务模式**：提供请求批准、帮我批准和完全访问三档权限；普通、Goal 与 Plan 模式沿用 Pi 会话事件管理状态。
- **字体与设置优化**：加快 Windows 字体枚举与搜索，列表统一使用当前界面字体，支持苹方 Regular、Medium、Bold；应用和 Pi CLI 的版本名称与版本号同排显示。
- **项目与输入交互**：完善无项目聊天、项目创建与选择、添加菜单、输入区域和设置浮层焦点行为。

## 下载与升级

| 文件 | 适用设备 |
| --- | --- |
| `Pi-Desktop-0.4.0-x64-setup.exe` | Windows x64 安装版 |
| `Pi-Desktop-0.4.0-arm64-setup.exe` | Windows ARM64 安装版 |
| `Pi-Desktop-0.4.0-portable-x64.zip` | Windows x64 免安装版，解压后运行 `Pi Desktop.exe` |
| `SHA256SUMS.txt` | 发布文件 SHA-256 校验值 |

升级继续使用已有的本地设置和 Pi 会话，无需迁移。发布包不包含个人配置、凭证或会话导出。

Windows x64 安装包内容与免安装版在独立配置目录中进行实际启动、Pi RPC 和提供商流程验证；ARM64 安装包完成构建及包内容检查，未在 ARM64 设备上运行。
