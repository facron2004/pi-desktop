# Pi Desktop v0.11.5

**发布日期**：2026-11-18

**内置 Pi**：1.5.2（`@earendil-works/pi-coding-agent`）

---

## 输入框图片生成与对话内呈现

- **图片生成融入输入框**：移除右侧工具面板中的独立生图页，改为在输入框内通过 `/image`（中文 `/图片`）、添加菜单或命令启动器进入生图模式，支持附加参考图、切换图片模型，以及在一个紧凑参数面板中选择比例、质量与生成数量（1–4 张）。
- **单次运行透传选项与自动豁免**：发送时通过 `/desktop-image` 扩展命令向当次运行的系统提示注入生图指令与选项（未匹配的后续提示不会继承），即使当前处于 Plan 模式也允许当次 `generate_image` 调用，同时豁免该工具的权限确认弹窗。
- **内联结果卡片与复用**：`generate_image` 调用固定呈现在回复正文下方，不折叠进过程流；自动跨已登记项目目录加载预览图，支持一键「设为参考图」、在文件管理器中定位及一键复用提示词，并将产物纳入变更交付物与文件树自动刷新。
- **灯箱预览完善**：图片灯箱同样支持「设为参考图」与「在文件管理器中显示」，顶部关闭栏下移避开原生标题栏窗口按钮区域并禁止误触发窗口拖拽。

## 会话提醒与侧栏

- **未读与失败标记跨重启持久化**：后台运行及定时任务结束留下的 `unread` / `error` 标记会保存在本地存储中，重启应用后侧栏会话行、项目行与启动器仍保留提示，直到打开对应会话或发起新运行才清除。
- **展开项目的状态圆点保持可见**：已展开的项目行不再隐藏子会话的未读、失败或等待输入圆点；鼠标悬停显示项目操作按钮时，指示点左移避让而不消失。

## 扩展市场、子智能体与终端体验

- **扩展市场安装反馈**：安装超时从 180 秒提升至 300 秒以覆盖大型 npm 依赖树；安装中的卡片展示实时 CLI 进度条与已用时长，并在失败时过滤 `npm warn deprecated` 警告以突出真实错误原因。
- **子智能体与术语统一**：标题栏子智能体卡片采用限高滚动列表与单行省略预览（完整内容保留在悬浮提示中）；全仓库文案及文档将「子代理」统一为「子智能体」。
- **嵌入式单终端精简**：在右侧工作区面板内仅打开一个终端标签时隐藏多余标签栏，将新建、复制、清屏与重启控制按钮悬浮到右上角；新增第二个终端时恢复标签栏。
- **更多交互细节**：
  - 项目选择器将图标与名称拆分为独立按钮，悬停图标变为关闭图标，可一键回到「不使用项目」状态。
  - 用户消息下方的复制与编辑操作栏紧贴气泡边缘消除悬停断层，且不再弹出冗余悬停提示；纯图标按钮在缺少 `title` 时回退读取 `aria-label` 作为悬停气泡文本，并在切换开关文案后原地刷新新提示。
  - 对话流移除行内工具与文件变更的多余悬停灰底、收窄运行摘要按钮宽度、去重已由错误卡片或工具过程覆盖的重复提示与已结束思考行，为外部链接增加右上箭头图标，并在刚发出新提示尚无新回复时保留上一轮 TPS 速度读数。
  - 更新依赖声明与锁文件中的 `@earendil-works/pi-coding-agent` 至 `^1.5.2`（实际锁定 `1.5.2`）。
