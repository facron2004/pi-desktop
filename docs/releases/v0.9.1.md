# Pi Desktop v0.9.1

本版本补齐会话用量与耗时统计、上下文估算，并加入会话归档和自定义桌面通知。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **会话统计**：摘要显示轮次/步骤、TPS、Token 与缓存命中率；详情提供模型耗时、工具耗时、平均 TTFT 与输出速度。客户端记录每轮可测量的耗时并按会话保存，Pi 有工具耗时数据时优先使用。旧对话没有计时样本时如实显示尚未记录。
- **上下文估算**：读取实时 `get_session_stats`；会话从磁盘重开时，使用最新助手消息用量和对应模型的上下文窗口估算，并标明来源。
- **归档会话**：从侧栏归档后可在设置中查看并恢复；原会话文件保持不变。
- **桌面通知**：浅色/深色主题的应用悬浮通知，支持点击返回对话、单条关闭和多条堆叠。
- **运行时工具**：文件差异在编辑期间及时更新；子代理面板支持打开任务对话并跟踪最新进度。
- **自动标题**：修复短标题标点、图片请求、快速追问和会话读取时序导致的漏标题；生成器不可用时使用脱敏后的首条请求兜底。
