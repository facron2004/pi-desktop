# Pi Desktop v0.11.6

## 更新内容

- **Windows 安装与更新**。新版安装和卸载向导支持选择安装位置。应用内更新显示安装包大小和下载进度，并在验证下载后启动静默更新。
- **托盘与会话导航**。从系统托盘打开运行中或最近的会话。侧栏支持按工作区和工作区树分组，也可切换为单列表并按归档状态筛选。
- **对话与输入**。改进草稿恢复、Markdown 流式渲染和会话统计。对话链接可在设置中选择用应用内浏览器或系统浏览器打开。
- **布局与性能**。对话工作区和工具面板的右边与底边贴齐窗口。优化 Git 状态读取、会话索引和设置页加载。
