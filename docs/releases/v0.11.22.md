# Pi Desktop v0.11.22

## 更新内容

- **提问停在输入框上**：模型或扩展发起单选提问时，问答卡停在该对话的输入框上方（侧边对话停在其侧边输入框），不再压暗并盖住正文；选项之外还可以直接写下自己的回答，发送的就是这段文字，记录里以「自定义回答」显示。计划审阅、工具授权、输入/编辑请求以及别的对话的提问仍是居中对话框。
- **安装版可以单独升级内置 Pi**：「检查更新」现在同时查询 npm 上最新的内置 Pi；发现新版本时可在「关于」页升级，新版本安装到应用数据目录并由应用启动，不改动安装目录里的文件。升级需要机器上有 npm，安装或校验失败会保留当前可用的 CLI；手动检查的「已是最新」提示也会说明内置服务另有更新。
- **定时任务记住对话归属**：任务可以选择每次新建对话或续用同一对话；更换项目后下一次运行在新项目里新建对话，不再续用旧项目会话；续用前会核对已保存会话确实属于当前项目，等待恢复期间也可以停止。
- **一轮结束后只留下答案**：已结束的回合默认折叠过程（评论、工具与思考），保留回答与运行摘要，摘要箭头可以展开；运行中的回合始终展开。
- **模型芯片立即回应选择**：模型与推理强度在命令发出前就显示所选值，Pi 确认后以它的记录为准；被拒绝时回滚并报错，只有 Pi 接受后才写入默认偏好。
- **错误提示收紧为两行**：内联错误行与对话错误条最多显示两行，完整内容留在 tooltip，不再附带复制按钮或侧边对话诊断入口。
- **侧栏「对话」标题就是折叠开关**：标题与箭头合成一个控件、不画背景；打开/收起状态按列表分别记住，搜索时自动展开。
- **项目文件夹编辑补齐**：编辑项目时文件夹列表始终有「添加文件夹」一行，主文件夹用「主要」标记，其余可一键「设为主要」，移除按钮带完整路径提示。
- **会话与导出的边界更严**：冷改名会在写入前核对文件身份（设备、inode、大小、时间、硬链接），文件被替换时拒绝写入；Markdown 导出在历史被截断时写明「较早消息可能缺失」，导出目标在写入过程中被改动则拒绝覆盖。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.22` 标签构建，产物与本机 `npm run dist` 一致。
- 随包内置的 Pi 仍为 **1.6.0**；安装版现在可以在「关于」页把内置 Pi 单独升级到 npm 上的新版本（需要机器上已安装 npm）。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
