# Pi Desktop v0.10.2

本补丁版本限制手机伴侣和自动标题服务的会话状态保留，避免长时间运行后随浏览、命名过的会话持续累积。

## 修复

- 手机伴侣只在事件流活跃时保留会话引用；单纯浏览会话列表或读取会话详情不会占用进程级引用，最后一条事件流关闭后会释放引用。
- 自动标题服务限制已处理会话与新草稿的跟踪数量；等待队列淘汰会清理关联计时器和重试状态，读取重试耗尽也会释放会话状态。

## 验证

- `npm run typecheck` 通过。
- `npm test`：666 项通过，1 项跳过；包含会话引用、状态上限与重试清理回归测试。
- Windows 安装包、免安装包与 SHA-256 清单已生成并核对。
