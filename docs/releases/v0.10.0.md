# Pi Desktop v0.10.0

本版本新增会话记忆、定时任务和手机伴侣，并加强项目安全、工作区并发保护与长会话处理。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **会话记忆**：Pi Desktop 可从已结束对话中提取长期有用的项目知识与明确偏好，按项目或全局注入新会话。设置页支持查看、删除、清空和关闭记忆；内容在持久化前脱敏，默认不从使用过外部工具的会话中学习。
- **手机伴侣**：在可信局域网中通过短时、一次性配对码连接手机，可浏览已登记项目和会话、阅读对话并发送消息。手机端不能访问终端、文件系统或任意 Pi 命令，发送仍沿用会话的 Pi 权限。连接使用 HTTP，网络流量不加密。
- **定时任务**：支持一次、每日和每周运行；每次任务使用独立会话。多个桌面实例共用任务记录与运行锁，关闭应用后可识别未完成任务。
- **项目安全与 Agent 默认值**：项目本地设置默认不受信任；在设置中明确开启后才加载。Agent 设置集中管理新会话的默认模型、推理强度、权限和模式，电脑操作另有独立开关。
- **Git 与工作区**：分支菜单支持 worktree 操作。Pi 会话和 Git 写操作按重叠工作目录互斥，并通过跨进程锁保护同一会话文件，减少并发写入造成的数据覆盖。
- **会话与工具可靠性**：会话和工作区文件读取校验路径并使用已验证的文件句柄；长会话可继续打开、搜索和统计；搜索支持取消过期扫描。增加上下文用量拆分、冷会话技能发现和会话标题同步。
- **桌面体验**：调整分支、文件、任务与设置界面，修复后台会话切换、运行状态和文件预览等边界问题。
