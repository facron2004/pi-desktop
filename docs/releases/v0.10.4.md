# Pi Desktop v0.10.4

本补丁版本减少长会话中同一渲染帧多条 Pi 事件造成的重复 transcript 复制和历史扫描。

## 修复

- 每帧积压的 Pi 事件在一份私有 transcript 副本上按序归约，提交后仍保持旧快照不变。
- 按消息 ID 与终端命令 ID 定位会话项，避免重复消息去重和终端输出更新逐项扫描历史。
- 批量处理继续为每个事件保留各自的会话、运行与轮次上下文。
