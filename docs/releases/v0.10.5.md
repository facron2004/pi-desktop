# Pi Desktop v0.10.5

本补丁版本降低长会话中侧边栏更新时重复遍历 transcript 和会话列表的成本。

## 修复

- 活动会话摘要复用 reducer 记录的变更链，按新增项更新预览、时间和消息数。
- 同一份会话列表的标准化路径索引在侧边栏会话、活动标题和运行项目路径之间复用。

## 验证

- `npm run typecheck` 通过。
- `npm test`：678 项通过，2 项跳过，0 项失败。
- `npm run dist` 通过；`node scripts/verify-package.cjs` 确认安装包内版本为 0.10.5，主进程、渲染器与远程伴侣文件齐全。
- Windows x64、ARM64、通用安装包和 x64 免安装包已生成，并已计算 SHA-256。

## 发布文件

- `Pi.Desktop-0.10.5.exe` — Windows x64/ARM64 通用安装包
- `Pi.Desktop-0.10.5-x64.exe` — Windows x64 安装包
- `Pi.Desktop-0.10.5-arm64.exe` — Windows ARM64 安装包
- `Pi.Desktop-0.10.5-portable-x64.zip` — Windows x64 免安装包
- `SHA256SUMS.txt` — 上述文件的 SHA-256 校验值
