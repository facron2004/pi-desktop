# Pi Desktop v0.10.19

本版本修正会话模型用时与工具用时的统计口径，避免遗漏长会话历史、重复累计，以及在休眠或系统时钟变化后显示失真的工具时长。

## 改进

- 模型用时累计完整会话中本地记录的生成时长，并通过助理消息时间戳和轮次 ID 识别已计时消息，避免把同一段历史再次加到统计中。
- 工具用时优先采用 Pi 提供的时长，其次采用客户端单调时钟测量；没有可信来源时不再以墙钟差值估算。
- 拒绝负数或非有限的 Pi 工具时长，避免无效数据进入统计。
