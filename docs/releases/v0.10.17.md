# Pi Desktop v0.10.17

本版本降低远程访问事件推送和定时任务轮询中的重复文件读取与 JSON 解析，并限制远程访问状态文件的大小。

## 改进

- 远程访问在推送流式事件时使用状态文件指纹跳过未变化状态的重复读取和解析；状态文件超过 64 KiB 或不是普通文件时拒绝读取。
- 定时任务轮询通过文件指纹跳过未变化任务文件的解析；只有任务到期时检查运行锁，并在没有待恢复运行时跳过恢复锁和数据文件读取。
