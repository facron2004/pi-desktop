# Pi Desktop v0.7.2

本版本完善任务模式和右侧工具面板，并修复终端命令、子代理目录、会话目标、Git 状态与大文件预览问题。内置 Pi coding agent 为 **1.4.0**。

## 主要更新

- **任务模式**：支持普通、目标、计划和子代理四种模式，新增 `/plan`、`/goal`、`/subagent` 命令；计划通过 `exit_plan_mode` 提交审批，目标条支持暂停、恢复、编辑与清除。
- **模式更新提示**：旧主进程不支持新模式时，提示完整退出并重新打开 Pi Desktop，避免只重启 Pi 子进程后反复出现 `Unknown mode`。
- **侧栏**：项目行不再绘制灰色选中气泡，只保留会话行自身的选中态，避免项目行与会话行叠成两块气泡。
- **侧栏对齐 MCode**：项目可戴表情图标与颜色（点项目图标打开选择器，支持中英文关键词搜索），会话行新增未读蓝点、失败红点与「等待输入」标签；项目行右侧改为常驻动作槽位，悬停时计数徽章让位给按钮，标题不再位移。
- **子代理**：支持单任务或最多 8 个任务的并行批次，并汇总输出、用量与失败信息；批量任务正确继承顶层工作目录，单个任务可覆盖目录。
- **右侧工具面板**：改为浏览器式页面标签，顶部显示已打开的页面与关闭按钮，「+」打开工具导航页；Files、File changes、Subagents 等功能作为导航入口。
- **子代理状态树**：移到右侧工具面板的 Subagents 页，采用 DeepSeek Harness 的紧凑目录样式：状态栏、任务名、当前活动，以及右侧 token 用量与耗时；点击任务进入该子代理的会话查看完整对话、工具调用和输出，切换聊天后继续更新，历史会话可恢复结果。
- **终端**：交接命令固定发送给接收它的终端标签，切换标签不再重复执行命令。
- **会话目标**：编辑草稿按会话隔离，切换会话后不会用原草稿覆盖另一会话的目标。
- **Git 状态**：跨项目打开会话时丢弃旧项目的异步查询结果和错误，避免分支与改动状态串入新项目。
- **文件预览**：悬停预览每页最多渲染 200 行，支持前后翻页，切换文件时重置页码。

## 验证

- 类型检查、310 项测试与生产构建通过。
- 6 组 Electron 界面回归检查覆盖真实 Pi 任务模式切换、真实子代理进度与会话重放、右侧工具面板标签导航、终端命令、目标草稿隔离和大文件分页；可用 `npm run test:ui` 复跑。
