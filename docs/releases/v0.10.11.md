# Pi Desktop v0.10.11

本版本修复了工作区与会话切换中的并发问题，并降低长回复流式渲染的重复解析开销。

## 改进

- 长回复按已完成的 Markdown 区块增量解析，后续文本只重新解析仍在增长的尾部。
- 按路径串行处理工作区添加和移除；跨窗口设置合并保留移除记录，避免旧设置恢复已删除的项目。
- 会话文件重绑定与 Pi 停止清理按序执行；会话状态只接受该会话最新的刷新结果，删除成功后回收关联的缓存状态。
- 模型、推理等级和提供商偏好写入增加竞态保护；提供商配置校验失败时避免部分更新文件。
- 定时任务的锁租约失效时仍继续释放对应的运行槽。

## 验证

- `npm run typecheck` 通过。
- `npm run dist -- --config.directories.output=release/v0.10.11` 成功生成 x64、ARM64 与通用安装包。
- x64 与 ARM64 的 ASAR 均确认版本为 `0.10.11`，主进程入口和远程页面资源齐全。
- 安装包与免安装包的 SHA-256 已写入 `SHA256SUMS.txt`。

## 发布文件

- `Pi.Desktop-0.10.11.exe` — Windows x64/ARM64 通用安装包
- `Pi.Desktop-0.10.11-x64.exe` — Windows x64 安装包
- `Pi.Desktop-0.10.11-arm64.exe` — Windows ARM64 安装包
- `Pi.Desktop-0.10.11-portable-x64.zip` — Windows x64 免安装包
- `SHA256SUMS.txt` — 上述文件的 SHA-256 校验值
