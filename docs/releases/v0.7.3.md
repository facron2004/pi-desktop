# Pi Desktop v0.7.3

本版本把对话右侧的任务栏改造成与 MCode 一致的会话面板，并让界面在局部出错时不再整页崩掉。内置 Pi coding agent 仍为 **1.4.0**。

## 主要更新

- **任务栏**：四段改为「环境信息 / 后台任务 / 进度 / 交付物」，与参考应用的分区一致。
  - 环境信息：分支显示为标题下的副标题；「变更」一行右侧是本次改动的增删行数；「提交或推送」打开提交对话框，右侧小按钮直接推送；「变更图谱」打开提交历史。
  - 后台任务：子代理任务列在右侧，状态点移到行尾，一眼能看出还在跑、已完成还是失败。
  - 进度：助手回复里的清单，右侧显示已完成步数，完成的步骤是实心圆点加删除线。
  - 交付物：本次写下的文件按目录折叠成树，点文件名在右侧面板打开。
  - 分区标题是纯文字加右侧箭头，折叠改为 180ms 的网格动画，不再瞬间收起。
- **分区级容错**：单条消息、单个工具卡片或右侧工具面板出错时，只显示「渲染失败」和重试按钮，其余界面照常可用。
- **会话树**：改用显式栈解析，超深的分支不会再撑爆渲染线程的调用栈。
- **后台会话缓存**：非当前会话最多保留 10 个，按最近使用淘汰，长时间开着多个会话时内存不再只涨不落。

## 验证

- 类型检查、单元测试与生产构建通过。
- 7 组 Electron 界面回归检查覆盖真实 Pi 任务模式切换、真实子代理进度与会话重放、右侧工具面板标签导航、终端命令、目标草稿隔离、大文件分页，以及任务栏的四段、任务行、清单、目录树与折叠；可用 `npm run test:ui` 复跑。
