# Pi Desktop v0.10.12

本版本降低多个应用进程同时写配置时相互覆盖的风险，修复远程访问启动竞态和流式回答期间的 TPS 显示，并让异常设置值回退到安全默认值。

## 改进

- Pi agent 设置、Marketplace、MCP 和提供商配置的读改写使用跨进程锁和原子文件替换；提供商配置与当前选择按序写入。
- 一个进程启动期间，若另一个进程关闭远程访问，启动中的实例会停止监听并沿用已保存状态。
- 合法 JSON 中若工作区路径或字符串设置类型异常，读取时会过滤或回退，避免启动和新会话流程因 `.trim()` 或路径解析崩溃。
- TPS 只使用已完成回答的 Token 和生成时长；流式增量不会让速度读数逐步漂移，也不会触发完整会话指标反复汇总。
