# Pi Desktop v0.7.1

本版本是依据视觉审查报告完成的质量修复版：集中修复深浅主题、设置、对话流、终端与窗口尺寸问题，并完成设计系统 token 治理。内置 Pi coding agent 保持 **1.4.0**。

## 主要更新

- **主题与浮层**：修复深色项目选择弹层白底与未定义设计变量；统一浮层的表面、描边、圆角与阴影；提高深浅主题文字、边框与浅色选中文本的对比度。
- **设置**：外观页显示真实生效的 token 颜色，默认值不再误标为 ChatGPT；预设与字体名称完整国际化；修复用量卡片拆词、设置导航换行和内容底部被硬切。
- **对话与文件**：文件变更行使用相对路径，新建文件补 `+N` 统计并压缩行高；错误回复下不再残留孤立的 Response details 图标；每次回复末尾的文件变更默认显示 3 行，剩余文件通过“展开显示”箭头查看。
- **文件面板**：右侧 Files 文件树补上独立滚动容器，长项目可以滚动查看全部文件。右侧工具面板打开/关闭增加滑入淡出过渡，浮层遮罩同步渐隐，收起过程中不再出现两个面板按钮。
- **终端**：重做为真实 PTY 终端（node-pty + xterm.js），有提示符、工作目录、交互程序和滚动缓冲；可在设置中切换 PowerShell / CMD / Git Bash / WSL，并支持复制、清屏和重启。
- **推理强度**：模型不支持当前或保存的强度时，自动落到最近支持的档位；冷启动尚未拿到级别时显示文字提示，不再出现“最高”配空白滑条。
- **终端与侧栏**：终端面包屑去掉多余竖线，复制/清空图标提高对比度；侧栏底部增加渐隐与分隔线，长列表不再把最后一行硬切。
- **窗口稳定性**：按窗口内容区保存并恢复尺寸，修复 Windows 高 DPI 下每次启动窗口变大的问题。
- **设计系统**：清理重复规则、语法残片与 `:has()` 覆盖补丁；57 处硬编码字号只保留 4 处有意为之的字号预览；全部 `transition: all` 改为具体属性。
