# Pi Desktop v0.10.20

本版本减少长会话在流式生成期间的重复计算，并降低会话内搜索索引刷新频率。

## 改进

- 用量栏每秒更新模型用时，但不再因此重新遍历整段会话；增量使用单调时钟测量。
- 会话内搜索在流式期间最多每 120 毫秒重建一次索引，切换会话或查询词时仍立即更新。
- 构建锁现在会透传打包参数，归档校验工具支持指定 app.asar 路径，便于把每个版本构建在独立目录。

## 验证

- `npm run typecheck` 通过。
- `npm run dist -- --config.directories.output=release/v0.10.20` 生成 Windows x64、ARM64、双架构安装包及 x64 解包目录。
- `node scripts/verify-package.cjs release/v0.10.20/win-unpacked/resources/app.asar` 确认归档版本为 0.10.20，包含主进程、渲染器与远程伴侣文件。
- 解包版在隔离的临时用户目录中启动成功，显示欢迎界面后以退出码 0 关闭。
- 四个发布文件的 SHA-256 已写入 `SHA256SUMS.txt`。
- 未运行测试套件。
