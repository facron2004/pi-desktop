# Pi Desktop v0.11.10

## 更新内容

- **IM 频道（飞书 / 微信）**。设置里新增「IM 频道」页，把飞书和微信接进 Pi 对话。飞书走自建应用的官方长连接，不需要公网 IP，也不需要自己写解密逻辑；微信通过开源的 wechatbot-webhook 桥接服务收发消息，应用本身不注入微信进程。每条频道绑定一个项目里的一个对话：在 IM 里发的消息就是这个对话的指令，任务跑完自动把最终回答推回去，Pi 需要确认时主动提醒。支持 `/help`、`/status`、`/stop`、`/new`。密钥保存在本机 0600 权限文件里，设置页只显示掩码，编辑时留空即保留原密钥。
- **手机远程控制补全**。配对后的手机不再只能看和发：运行中的对话可以从手机直接停止；Pi 的选择 / 确认 / 输入 / 编辑对话框直接在手机上回答，桌面和手机谁先答都行，另一侧自动关掉卡片；在会话列表里可以发起新对话，第一条消息发出后自动进入该会话。重连时未关闭的对话框会从快照恢复。
- **对话框应答广播**。应答扩展对话框时，主进程向所有转发过这个对话框的表面（手机、IM 频道）广播关闭事件，不会再出现「桌面已经答了、手机还挂着一张等待卡片」。
- **内置 Pi 升级到 1.6.0**。随应用分发的 agent 本体升级到 Pi 1.6.0，终端、更新与草稿几处随之调整。
- **大段回答逐帧显现**。有的服务端会把整整一段正文放在一个增量里，原先会在同一帧全部刷出。现在按屏幕刷新逐帧推进可见部分，正常节奏的流式输出仍即时显示；标点和代码块也不会先于构成它的文字出现。
- **终端标签自带目录**。每个终端标签记住自己创建时所在的项目目录，切换视图不会把正在跑的 shell 和 scrollback 重开。关闭标签会结束它的整棵进程树（Windows 上连同子进程），退出应用会等 PTY 清理完成再收尾。
- **草稿与附件**。草稿快照超出浏览器存储配额时，会用上一次快照里仍然挂着的图片重试，即使退化成纯文本与文件引用也能保住更早的草稿；粘贴的图片落在粘贴那一刻的会话目录，之后切换项目不会把它写到别处。
- **更新提示只静音该版本**。关掉某个版本的更新提示后，只有那一个版本不再打扰，下一个版本照常提示。
- **编辑用户消息后可以继续**。会话内回退会写入一条分支记录，重新打开这个会话仍停在你编辑的位置，而不是回到原分支末尾。
- **「等待模型响应」只在还没有输出时出现**。这一轮一旦有了思考、正文或工具行，等待下一段内容时只显示「正在处理…」，不再把等待文案压在已经能读的答案上面。
- **项目列表**。项目管理对话框去掉了与侧栏重复的「添加文件夹」按钮；新添加的项目文件夹固定排在列表第一行（即使另一个窗口同时写了顺序），已存在的文件夹重开时位置不变。
- **应用提示居中**。「项目已创建」这类浮动提示改为在窗口正中出现，不再从右上角滑入；它依旧不挤压输入框、不挡住背后的点击。
- **目标标记**。目标条、模式切换按钮与添加菜单里的靶心图标中心改为实心，小尺寸下不再露出一点背景。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.10` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
