# Pi Desktop v0.11.16

## 更新内容

- **侧边对话（Side Chat）**。每个主对话旁边多了一个只读的伴聊面板：它有独立的 Pi 进程与独立的会话文件（`_side-chats/`），跟随主对话绑定，提问不会打断主对话正在做的事。每轮前会注入主对话的最新摘要，需要细节时用 `inspect_main_conversation` 读完整轮次、工具输出与 diff，用 `inspect_main_changes` 读会话改动或工作区未提交改动。可以把选中的正文、某个回合、工具调用、报错或文件 diff 作为引用；也能用预设一次问清「解释当前进展 / 总结决策 / 诊断错误 / 拆解计划 / 审查会话改动 / 审查工作区改动」。`/side [问题]`、`Ctrl+Shift+L`、标题栏按钮、任务轨「进度」的拆解按钮和右键菜单都能打开。它不能写文件、执行命令或调用 MCP；模型与推理强度按侧边对话单独保存，不改变应用默认。
- **蜂群页面重做**。分成概览、智能体、派发三个视图：概览给出读数、每个 worker 的任务 lane 与最新活动流；智能体可按状态筛选、展开实时输出或报告、用方向键移动、逐个停止；派发是按状态筛选的派发日志，点一行打开对应子任务对话。历史名册里的 worker 显示「之前活跃」，「进行中 / 排队中」读实时队伍而不是派发日志。
- **模型切换不再卡住**。选择模型后菜单立即收起，芯片上转圈等待；`runtime.has`、冷启动、`set_model`、设置写入与快照刷新都有期限，失败会释放「正在切换」锁，下一次点击可以正常重试。
- **更新与安装更稳**。安装负载先复制到暂存目录并逐个校验长度（`app.asar` 按文件读取而不是当包解析），校验通过才交换，失败可从备份恢复；被中断的安装不再留下接近完整的副本反复重试。
- **其余修复**。内存账本写入加重入保护并隔离损坏文件；长会话的元数据读取与全文搜索修正；定时任务可停止、损坏的 `scheduled-tasks.json` 会被隔离而不是永久卡死；关闭终端标签无条件释放原生 PTY；补齐 RPC 参数、权限与子智能体边界测试。
