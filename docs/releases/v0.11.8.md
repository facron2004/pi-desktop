# Pi Desktop v0.11.8

## 更新内容

- **终端不再随视图切换重启**。以前打开另一个项目里的对话、或切换项目，会让所有终端标签重建并杀掉正在跑的 shell——构建、长任务、ssh 会话连同 scrollback 一起丢失。现在每个终端标签绑定它创建时的项目目录：视图怎么换，已经开着的 shell 都保持原样；新开的标签才继承当前项目。
- **定时任务可随时停止**。运行中的任务在右侧详情页新增「停止运行」动作：只停止这一次运行，原调度完整保留（启用状态与下次执行时间都不变）。此前暂停、更多、删除在运行期间全部置灰，一次挂住的运行会让任务永远停在 running。删除任务时也会停掉它正在跑的那次运行，不再留下看不见的 agent。
- **窗口控件**。设置页打开时窗口无法最小化的问题已修复：全窗口层展开时最小化与最大化保持可用，只有关闭按钮在「正在等待你回答」的层出现时才受守卫。同时页面内键盘焦点不再被遮罩层抢走。
- **对话阅读**。思考内容改为按段落排版，步骤之间原本空出的整行收紧为面板自身的间距，长思考块读起来更紧凑。
- **侧栏标识**。应用名改为像素字标（TUI 风格），随主题取色，`i` 上的点保留品牌珊瑚色。随附独立矢量 `build/wordmark-pixel.svg`，组件与资产的绘制由测试守护一致，改一处忘另一处会直接失败。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.8` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
