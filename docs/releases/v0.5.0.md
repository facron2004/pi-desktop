# Pi Desktop v0.5.0

本次发布汇总提供商管理、会话过程展示、项目切换与字体优化，并修复主按钮的双边重叠。此前的 v0.4.0 开发改动一并包含，内置 Pi coding agent 保持 **1.4.0**。

## 主要更新

- **提供商与模型管理**：按提供商卡片配置 Base URL、API Key，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Gemini；独立编辑、确认删除，保存的密钥不回传界面。
- **模型参数与连通性**：拉取上游模型时填入上下文长度、最大输出、推理、图片输入与价格；标明参数来源，缺失项可手动补充。支持模型列表或最小推理请求检测，空闲会话可立即刷新配置。
- **会话过程展示**：连续工具操作合并为可展开的过程记录，完善思考、命令、失败详情与运行状态显示。
- **项目与运行稳定性**：改进项目和分支标记、重复项目合并与移除确认；移除后保留文件和历史会话。修复项目切换的短暂断线提示，隔离退出中旧进程的事件，并延长可中止的限流重试预算。
- **界面与字体**：去掉主按钮的内侧高光双边，保留键盘焦点提示；改善窄窗口表单、操作按钮和下拉框。字体列表使用当前界面字体，加快枚举和搜索，支持苹方 Regular、Medium、Bold，版本名称与版本号同排显示。
- **权限与任务模式**：包含请求批准、帮我批准、完全访问，以及普通、Goal 和 Plan 模式。

## 下载与升级

| 文件 | 适用设备 |
| --- | --- |
| `Pi-Desktop-0.5.0-x64-setup.exe` | Windows x64 安装版 |
| `Pi-Desktop-0.5.0-arm64-setup.exe` | Windows ARM64 安装版 |
| `Pi-Desktop-0.5.0-portable-x64.zip` | Windows x64 免安装版，解压后运行 `Pi Desktop.exe` |
| `SHA256SUMS.txt` | 发布文件 SHA-256 校验值 |

升级继续使用已有的本地设置和 Pi 会话，无需迁移。发布包不包含个人配置、凭证或会话导出。

Windows x64 安装包内容与免安装版在独立配置目录中进行实际启动、Pi RPC 和提供商流程验证；ARM64 安装包完成构建及包内容检查，未在 ARM64 设备上运行。
