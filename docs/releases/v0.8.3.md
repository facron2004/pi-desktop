# Pi Desktop v0.8.3

本版本把使用情况页对齐参考界面、补上系统托盘持久化，并让任务栏图标显示 Pi 像素标而不是 Electron 原生图标。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **使用情况**：消耗总览改为两行四列 —— 上排总成本、总请求数、真实消耗 Tokens、缓存命中率，下排新增输入、输出、缓存写入、缓存命中；「真实消耗 Tokens」加下划线强调，三个需要解释的数字带内联提示气泡。热力图改为近 180 天，单元格随列宽铺满整行，不再横向拖动。模型用量分布右侧改为限高抽屉，超出部分下滑查看；左侧柱状图的柱子按标签行预留高度，最左侧那根不再顶出绘图区。上一版遗留的周期卡片、用量明细与模型列表样式一并清掉。
- **窗口按钮**：打开的对话框会盖住整条标题栏，现在系统窗口按钮使用遮罩合成后的颜色，与同一行其余部分一致；关闭浮窗后回到标题栏底色。关于页卡片与页面同色。
- **托盘**：设置「常规」新增「托盘持久化」开关，打开后关闭主窗口收进系统托盘，托盘图标单击或双击都能把窗口叫回来，右键菜单为「显示主窗口 / 退出」。托盘模式下再次启动应用会聚焦已经在托盘的窗口，不再开出第二个看不见的窗口。
- **任务栏图标**：开发运行时的进程是 `electron.exe`，窗口没有自己的图标时任务栏画的是 Electron 原生图标。窗口现在携带 Pi 像素标的 `.ico`；AppUserModelID 改用 shell 从没见过的 `dev.pi.desktop.v2`（与安装包 `appId` 一致），并且只挂在窗口上而不挂进程 —— Windows 会把一个 id 连同第一次登记时的图标缓存下来，而进程级登记用的是可执行文件的图标，所以旧 id（`dev.pi.desktop`）永远停在 Electron 原生标上。任务栏按钮与 Alt-Tab 现在都是像素标，按钮标题是 "Pi Desktop"；托盘图标取 .ico 中 32px 的一帧。

## 验证

- `npm run typecheck`、`npm run build` 通过；`npm test` **409 项全部通过**。
- 设置浮窗打开时，系统窗口按钮使用遮罩合成后的颜色，与同一行其余部分一致；关闭浮窗后回到标题栏底色。
- 托盘开关在设置「常规」里可见并生效：点击后设置文件写入 `trayPersistent: true`；关闭主窗口后进程仍在运行、窗口已隐藏。运行中窗口的图标句柄导出为 48×48 与 24×24 的 Pi 像素标，任务栏按钮用的就是它。
- 打包产物 `release/win-unpacked` 的 `resources/` 已带 `icon-pixel.ico`，打包版取到同一个像素标，关窗后同样收进托盘。
- 任务栏用 `PrintWindow` 渲染真实的 `Shell_TrayWnd` 抓下来看过：开发运行与打包版的按钮都是 Pi 像素标，标题是 "Pi Desktop"；同一批对照实验确认了 AppUserModelID 必须换成新 id、且只能挂在窗口上。
- 产物：Windows x64、ARM64 和通用安装版，x64 免安装 ZIP，以及 `SHA256SUMS.txt`。
