# Pi Desktop v0.11.13

## 更新内容

- **蜂群任务进入子智能体视图**。蜂群模式下每派一个活就是一个工具调用：同步等待的显示运行中 / 完成，`wait: false` 的异步派发显示为「已派发」而不是完成。子智能体面板、标题栏角标和右侧「蜂群」页读取同一份任务列表，点击行可以直接打开对应子任务的对话。
- **文件图标记号更全**。文件树的类型标识从七种扩到二十余种：HTML `<>`、Vue、Svelte、Python `PY`、Rust `RS`、Go `GO`、C、C++、C#、Java、Kotlin、Swift、Ruby、PHP、SQL `DB` 与通用 `</>`，字号随标记长度自适应。类型表改为从语法高亮共用的语言数据推导，避免两处各维护一份。
- **进度清单会自己收尾**。用 `desktop_todo` 维护的任务，如果最终回复里按同样的步骤和文字列出了清单并勾选了已验证项，右侧「进度」会用最终回复补齐完成度，不再停在旧状态；`desktop_todo` 的使用指引也要求模型在回复前同步一次清单，或在无法调用工具时用 Markdown 清单复述。
- **模式快捷键不再写多余提示**。`/plan`、`/goal`、`/swarm`、`/plugin` 这些由扩展直接处理的命令自己会发布状态，输入框不再额外插入一条「Pi 已直接处理」；其他被直接处理的命令改为跟着界面语言显示「Pi 已接收 …」。
- **更新按钮的进度环**。下载与校验完成后圆环立即消失，不再显示一个满环；安装阶段提示改为「正在重启安装…」，避免满环一直挂着像没装完。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.13` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
