# Pi Desktop v0.10.13

本版本修复 Windows Pi 命令 shim 无法启动的问题，限制 RPC 子进程诊断日志的内存占用，并让隔离运行不再读取系统用户目录下的 Pi 配置和会话。

## 改进

- 通过 `cross-spawn` 启动 `.cmd` 和 `.bat` 命令，保留参数边界，避免 shell 元字符被解释。
- RPC 保留的 stderr 诊断尾部限制为 256 KiB，同时继续限制为最多 200 行。
- `PI_DESKTOP_USER_DATA` 现在也隔离 `HOME`、`USERPROFILE`、Pi 配置目录和会话目录。
