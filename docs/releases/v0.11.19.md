# Pi Desktop v0.11.19

## 更新内容

- **已归档对话按项目分组，可折叠**。设置 → 已归档对话 不再是平铺的一列：每个项目一个标题行（项目名 + 该组对话数），对话挂在标题下面。组顺序跟随侧栏的项目顺序，项目顺序里没有的文件夹用自身名字兜底，「无项目对话」始终排在最后——和侧栏的归档区用的是同一个分组规则（`groupArchivedByProject`），所以两处读起来一致。
- **标题行就是折叠开关**。左侧 caret（收起朝右、展开朝下）、项目名、数量，带 `aria-expanded`；折叠只隐藏该组的对话，标题行留在原处，随时点回来。展开/收起状态保存在 localStorage，关掉设置再打开不会重置，默认全部展开。
- 组内的每一行不再重复项目名（标题已经说明了），保留相对时间与消息数。

本版同时包含 v0.11.18 的内容：设置 → 关于 的「应用版本」一行只显示版本号，不再带「发现新版本」徽标和提示。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.19` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
