# Pi Desktop v0.10.21

本版本继续减少长会话流式搜索的重复工作。

## 改进

- 会话搜索复用未变化轮次的搜索结果；流式更新时只扫描发生变化的轮次。首个变化位置通过轮次引用比较确定，不依赖可能被回收的中间快照。
- 搜索结果保持会话顺序，并限制为最多 50 项；切换会话、工作区或查询词时立即重新搜索。

## 验证

- `npm run typecheck` 通过。
- `npm run dist -- --config.directories.output=release/v0.10.21` 生成 x64、ARM64、通用安装包及 x64 解包目录。
- `node scripts/verify-package.cjs release/v0.10.21/win-unpacked/resources/app.asar` 确认归档版本为 0.10.21，主进程、渲染器和远程伴侣入口齐全。
- 解包版在隔离用户目录中启动并显示欢迎页，截图完成后以退出码 0 关闭。
- portable ZIP 根目录含 `Pi Desktop.exe`；四个发布文件的 SHA-256 已写入 `SHA256SUMS.txt`。
- 未运行测试套件。
