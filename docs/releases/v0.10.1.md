# Pi Desktop v0.10.1

本补丁版本修复手机伴侣设置页的安全提示在中文界面中未能翻译的问题。提示内容包含局域网传输未加密以及手机消息权限说明。

## 验证

- `npm run typecheck` 通过。
- `npm test` 包含安全提示翻译回归测试。
- Windows 安装包、免安装包与 SHA-256 清单已生成并核对。

## 发布文件

- `Pi.Desktop-0.10.1.exe` — Windows x64/ARM64 通用安装包
- `Pi.Desktop-0.10.1-x64.exe` — Windows x64 安装包
- `Pi.Desktop-0.10.1-arm64.exe` — Windows ARM64 安装包
- `Pi.Desktop-0.10.1-portable-x64.zip` — Windows x64 免安装包
- `SHA256SUMS.txt` — 上述文件的 SHA-256 校验值
