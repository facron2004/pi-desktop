# Pi Desktop v0.11.20

## 更新内容

- **键盘可以走完整个界面**：侧栏、会话树、文件树、设置搜索与结果、会话轨道、会话搜索、全文搜索、子智能体目录、定时任务列表和项目图标选择器都支持方向键，并各自只保留一个 Tab 停靠点。文件树和会话树用左右键展开/收起分支，emoji 网格按行列移动（Home/End 到首尾），图片条只有当前图片是 Tab 停靠点，用方向键逐张切换。
- **终端标签条成为真正的 tablist**：角色、选中状态和 roving tabindex 落在可聚焦的标签按钮上，左右键切换标签，Home/End 到首尾；关闭按钮仍是独立的 Tab 停靠点。
- **焦点跟着动作走**：新对话把光标放进输入框；新建定时任务从名称字段开始；从搜索或快捷键打开对话时，侧栏自动展开所在项目并滚动到该行。正文本身成为可聚焦滚动区（`role="region"`），`PageUp`/`PageDown`/`Home`/`End` 可以直接翻阅。
- **最大化工具面板后，对话区不可误触**：`.main__body` 与任务栏在面板覆盖期间为 `inert`，Tab 和点击不会落到看不见的控件上；标题栏、侧栏和面板自己的退出路径保持可用。
- **空状态给出下一步**：首次使用的项目树和空对话列表分别提供「打开项目」和「新对话」；文件、全文搜索、图片与定时任务页的空状态也提供「打开项目」，图片页在未打开项目时不再误报「此项目没有图片」。
- **读取失败可以重试**：文件预览、图片舞台（包括字节到达但无法解码的情况）和会话树各有一个「重试」；启动失败时欢迎页也提供「重试」，重试前会清掉旧错误，并复用启动过程已有的订阅清理，避免叠加监听。
- **错误信息可以复制**：行内错误和线程错误横幅都带复制按钮，复制完整错误文本（摘要行背后 `title` 里的原始内容），方便直接贴进问题报告。
- **设置搜索**：可以按设置项名称找到所在页面，打开后滚动并闪烁命中项；`Ctrl+F` 聚焦搜索框，上下键在页面列表和结果之间移动，结果数量通过隐藏的 live region 播报。
- **侧栏与历史**：侧栏方向键逐行走动，顶部回到搜索按钮；折叠的历史可以一次「Load all」，每帧加载一页而不是一次性挂载；回答可以从自己的行复制为 Markdown（含代码围栏）。
- **导出与提示**：会话可以导出为 Markdown；导出成功（Markdown 和 HTML）的提示卡可直接打开文件，提示在悬停或聚焦时暂停消失计时；中文界面里主进程消息的占位符会在填入值之前翻译。
- **排队提示可撤回**：运行中排队的提示可以放回编辑器或丢弃，两者都不打断当前回合。
- **响应性修复**：模型选择、停止运行和终端转交不再因为冷启动或串行超时看起来卡住；文件搜索和全文搜索都可以用 Enter 打开第一条命中。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.20` 标签构建，产物与本机 `npm run dist` 一致。
