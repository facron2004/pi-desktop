# Pi Desktop v0.10.6

本补丁版本加固会话文件的重新打开与删除流程，并更新 Electron 安全修复。

## 修复

- 冷会话启动时重新验证会话文件；文件已删除或路径已变化时明确失败，不再静默启动空白对话。
- 删除会话前，在文件变更锁内复核文件身份，避免路径被替换后误删另一个会话文件。
- Electron 更新至 44.10.2，包含上游 TLS 证书验证安全修复。

## 验证

- `npm run typecheck` 通过。
- `npm test`：682 项通过，2 项跳过，0 项失败。
- `npm run dist` 生成 Windows x64、ARM64、通用安装包和 x64 免安装包。
- `node scripts/verify-package.cjs` 确认归档版本为 0.10.6，主进程、渲染器与远程伴侣文件齐全。
- `npm audit --omit=dev`：0 个漏洞。
- 已计算全部发布文件的 SHA-256。
