# Pi Desktop v0.9.0

本版本新增插件与技能市场，重做了侧栏项目顺序与拖动手感，补上输入框下方的用量读数，并修掉一批交互与布局问题。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **插件与技能市场**：侧栏「插件与技能」打开一个独立页面，内置 47 个插件与 25 个技能的策展快照（来自 GitHub 与 pi.dev 目录），支持搜索、分类与星标筛选、按星数或更新时间排序，以及「我的」只看已安装。安装全部通过 `pi install` 执行，渲染进程只传条目 id，主进程回查快照后才拼命令，安装前二次确认；「刷新」跑四条 GitHub topic 搜索并把结果原子写入缓存，离线时退回内置快照。「管理」页可启用、停用、移除已装包，并直接开关或删除 MCP 服务器。
- **修复插件市场安装失败**：无项目时安装命令的工作目录是 `<userData>/chats`，而该目录从未创建；Windows 上 `spawn` 遇到不存在的 cwd 会抛 `spawn <exe> ENOENT`，错误信息指向可执行文件，看起来像「Pi 找不到」。现在该目录会被创建，且 `runPiCli` 在目标目录消失时回退到 `process.cwd()`，安装恢复正常。
- **侧栏项目不再「用哪个置顶」**：显示顺序由 `settings.projectOrder` 保存，同时覆盖已登记项目和仅从会话发现的项目；`lastOpenedAt` 只作为活跃时间记录，不再参与排序。拖动项目改为移动 4px 立即开始（去掉 420ms 长按），带插入落点线、边缘自动滚动与指针捕获；不想拖时可用动作菜单的「上移 / 下移」。
- **用量读数**：输入框正下方新增居中一行 —— 左侧是上下文圆环（弧长即占用比例，点击打开 Pi 的上下文面板，含压缩入口与自动压缩/重试开关），右侧是可点击摘要（用量、缓存命中率、生成速度、首字延迟）。点击摘要展开明细浮窗：Token 拆分与费用、命中率及其公式、生成口径说明、消息统计。首字延迟与生成速度由客户端在首个文本增量与 `message_end` 之间计时派生，历史会话没有该数据时如实显示 `—`。
- **任务状态栏**：改为内容自适应高度，不再固定撑满右侧；收起与展开有宽度/透明度过渡。干净工作树时「变更」行不再显示孤零零的 0。
- **desk page**：进入「插件与技能」或「定时任务」后，聊天输入框、目标栏、计划条与任务状态栏都不再残留在下方；定时任务的删除改为行内二次确认，不再弹系统对话框。
- **设置**：移除「插件」页（其内容已由市场「管理」页与「常规 → 项目安全」承担），新增「键盘快捷键」页；`Ctrl+,` 可打开设置，快捷键表统一到 `lib/shortcuts.ts`，与 `Ctrl+/` 弹窗共用同一份渲染。
- **外观修复**：用量热力图恢复 12px 小格并按列均分铺满整行，间距回到 4px；修掉两处按钮重影 —— 定时任务行内确认时图标按钮与确认条挤在同一槽位、工具面板标签关闭按钮被旧规则的 `margin-right` 推离原位。

## 验证

- `npm run typecheck`、`npm run build` 通过；`npm test` **439 项全部通过**。
- 插件市场用真实渲染器端到端跑通：安装由 `spawn ENOENT` 变为「安装完成」，管理页出现已装条目，刷新与管理均无 JS 错误。
- 侧栏顺序两项审计：切换项目后行位置不变；拖动后 DOM 与 `settings.json` 同序；仅从会话发现的项目被选中登记后位置不动。
- 用量行审计：与输入框中线偏差 0px，圆环在位，摘要 4 项可点击，浮窗含 ≥8 行明细并可按外部点击关闭；真实 Pi 运行确认计时字段确实写入。
- desk page 审计：两个页面下 `main__body` 只剩页面本身，返回后聊天区完整恢复；定时任务删除全程 `window.confirm` 调用 0 次、模态层 0 个。
- 设置与快捷键审计：导航不再含 Plugins、含 Keyboard shortcuts；`Ctrl+,` 能打开设置；设置内快捷键页与 `Ctrl+/` 弹窗同为 25 行且都含两条新快捷键。
- 任务状态栏交付物平铺检查仍通过（无目录行、单列单行高、重名才带目录、路径留在 tooltip）。
