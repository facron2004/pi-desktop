# Pi Desktop v0.11.21

## 更新内容

- **键盘可达性收尾**：Diff 行号、分屏行、变更文件列表、提交历史与提交详情文件、工具栏标签条、对话轨道各自只保留一个 Tab 停靠点，方向键逐行走、Home/End 到首尾；关闭标签后焦点回到标签条；Escape 逐层归属——先清空过滤器、再关闭浮层，关闭浮层不再误触「停止运行」。
- **应用级快捷键不再吞键**：输入框里的 `Ctrl+N`、`Ctrl+F` 与 `Alt+↑/↓` 不再抢走焦点或滚动正文；`Ctrl+Shift+F` 可从任何位置打开对话搜索（折叠的侧栏会自动展开）；打开某一层的那个键，在该层内部也能把它关掉（设置、快捷键列表、会话树、命令面板），终端自己的 `Ctrl+\`` 同理，关闭后键盘交还面板角落的开关。
- **终端成为完整表面**：`Ctrl+Shift+C` 复制选区（空选区时把键还给 shell，`Ctrl+C` 仍能中断命令）、`Ctrl+Shift+V` 粘贴（阻止浏览器二次粘贴）、`Ctrl+Shift+Home/End` 跳到缓冲区首尾；右键菜单提供复制 / 粘贴 / 清屏，Escape 关闭并把键盘交还 shell。
- **图片页补齐动作与缩放**：可「另存一份」「用系统查看器打开」；新增缩小 / 适应 / 放大与 `+` / `-` / `0` 键盘缩放，放大后从左上角排布，可用滚动条或方向键平移；同时修复 Browser 与 Images 页在工具面板里完全没有加载样式的问题（样式表原先只被 Inspector 导入）。
- **错误与空态都能自救**：浏览器页打不开的页面会写明地址与原因并提供重试，空视图提示该在地址栏输入什么；Diff 读取失败可重试，且重试会丢弃该文件的缓存；定时任务写了一半时切换行 / 新建 / 关闭会先内联询问，不再静默丢弃。
- **草稿与搜索状态**：侧边对话的草稿（含附件）与主草稿一样能跨重启恢复；`@` 列表按原因给出五种空态并说明结果是否被截断；命令面板与文件列表支持 Home/End 与 PageUp/PageDown，Shift+Tab 退出列表而不是插入。
- **其它修复**：工具面板打开新标签后自动选中并保持在视野内；变更文件、提交历史与提交详情支持方向键遍历；对话轨道收窄后的显示成为偏好而不是一次性设置；侧边对话草稿键在重启后保留；启动失败、文件读取失败与图片解码失败都提供「重试」。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.21` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
