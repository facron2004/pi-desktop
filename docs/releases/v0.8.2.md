# Pi Desktop v0.8.2

本版本聚焦流式对话的阅读体验与启动稳定性：流式正文按 Markdown 块渲染，完成后的回合顶部显示可折叠的完成摘要，并修复了启动时可能停在无项目状态的问题。内置 Pi coding agent 为 **1.5.0**。

## 主要更新

- **流式输出**：长回复拆成已完成 Markdown 块与实时尾部，只重解析正在增长的尾部；同一帧的连续文本增量先合并再进入 reducer。
- **代码块**：修复 Markdown 代码块一直未进入 `CodeBlock` 的问题，恢复语言栏、复制/询问按钮和 Shiki 语法高亮。
- **完成态摘要**：移到回合顶部，显示「已完成，用时 8分43秒」和折叠箭头；展开可查看当轮工具/思考过程，答案始终保留。
- **启动**：没有可恢复项目时直接进入无项目新对话并持久化 `activeWorkspaceId: null`，不再出现「打开项目文件夹」的空占位状态。
- **模型切换**：启动后的第一次模型切换不再等待 Pi 冷启动。冷会话只保存选择（草稿随下一条消息生效，已保存会话在下次启动时补发 `set_model`），模型面板的推理档位直接从本地目录读取，不再在首次打开时动态加载整个 Pi agent。模型选择器同时补上最近使用（前三个置顶、其余收进「其他模型」）、分词搜索和上下键选择。
- **设置页**：关于页进入时不再自动检查更新；外观前景改为纯黑，项目名使用更浅一级的颜色；项目安全与电脑操作的开关统一回到右侧；子代理模型选择器缩短；移除外观高级里重复的界面语言；色调缩为「正常对比度 / 强对比度」。
- **使用情况**：总览压缩为一行指标（请求数、总成本、输入、输出、缓存命中、缓存命中率），由一个周期选择器控制；热力图颗粒放大并改用自定义浮窗显示当天 Token 与缓存命中率；模型用量改为左侧彩色柱状图、右侧模型明细；关于页卡片与页面同色，窗口按钮区域与标题栏颜色统一。
- **界面细节**：任务栏交付物保持平铺文件清单；会话轨道、计划解析与文件变更统计减少流式期间的重复计算。

## 验证
