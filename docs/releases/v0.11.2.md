# Pi Desktop v0.11.2

**发布日期**：2026-11-14  
**内置 Pi**：1.5.2（`@earendil-works/pi-coding-agent`）

---

## 多 RPC 并行与并发交互优化

- **空闲运行时 LRU 控制（`MAX_IDLE_RUNTIMES = 4`）**：多会话切换后自动淘汰长期闲置的后台 Pi RPC 进程，同时使用同毫秒单调序号避免淘汰顺序错乱，并严格跳过运行中、正在写入、启动/停止/收尾/绑定中、排队等待工作区锁或存在待响应 UI 弹窗的会话。
- **IPC 流式事件合并与归因**：`bridgeRuntime` 在主进程侧对相邻 `text_delta` / `thinking_delta` / `toolcall_delta` 及中间 `tool_execution_update` 进行微任务合并，在生命周期、状态切换或重绑定事件前同步刷新队列，并将 `runtime:stderr` 携带 `ownerId` 发往对应会话。
- **前端渲染与状态隔离**：`useAppStore` 将挂起增量与通知合并在同一动画帧中原子落地，支持后台标签页兜底刷新、后台会话惰性绑定及已删除会话墓碑防护（`deletedSessionKeys`）；`Sidebar` 会话行组件采用 `memo` 与稳定回调减少多会话并发输出时的重渲染。
- **启动暂存清理**：应用启动时清理孤立的临时暂存文件（`cleanupOrphanedScratchFiles`）。

## 新增功能

- **应用内更新与 Windows 自动安装**：内置版本更新弹窗与安装器，访问 GitHub Release API 校验非草稿/非预发布版本与 SHA-256 摘要，在确认无活动任务后下载并拉起对应架构安装包（x64 / arm64 / 通用）。
- **Pi 官方包目录支持**：扩展市场接入 `pi.dev/packages` 官方 npm 目录，支持关键词搜索、分类筛选、下载量排序与分步加载，并实时流式展示 `pi install` 输出。
- **图片生成面板与工具**：工具栏新增图片生成页，支持按项目保存生成历史记录、安全预览图与参数记忆，同时补充主进程与 Pi 工具端图片生成接入。
- **标题栏子代理状态栏**：在应用顶部展示正在运行及已完成的子代理状态、最新摘要、耗时、Token 数与模型名，点击可直接在侧栏中定位子代理会话。
- **自定义快捷键**：快捷键列表支持分类搜索与设置内编辑（替换、追加与重置快捷键绑定），应用菜单栏同步按当前系统（Windows / macOS）与自定义绑定展示快捷键。

## 修复与改进

- **文件树变更与全量双索引**：新增「变更文件」与「全部文件」双视图索引及折叠/展开记忆，清晰区分修改、新增、删除、重命名与冲突状态。
- **会话滚动记忆与上下文压缩反馈**：为每个会话独立保存滚动高度与“跟随最新输出”标志；精确分类上下文压缩超时、无历史可压、已压缩、取消及外部扩展接管等错误提示。
- **远程访问会话状态同步**：改进远程协同客户端的发送排队与重连会话消息恢复一致性。
