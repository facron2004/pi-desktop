# Pi Desktop v0.11.1

本版本改进启动与流式对话体验，加入 Mermaid 图表和产品经理插件套件，并完善定时任务、会话恢复及运行时可靠性。

## 启动与对话

- 三色 Pi 图标拆为 16×16 矩阵方格，在初始化期间循环点亮；主界面准备完成后自动淡出。适配明暗主题和系统减少动态效果设置。
- 加载画面直接出现在 HTML 首屏，窗口可以在 React 和会话恢复完成前显示。
- 流式正文下方不再重复显示“正在撰写回复”或工具运行提示；过程摘要与正文共用左边界，顶部耗时保持简洁单行。
- 重试、等待确认、上下文压缩、断线和停止提示继续显示；完成后的过程与工具仍可展开查看。

## 图表与产品工作

- Mermaid 代码块渲染为交互图表，支持缩放、适应宽度、全屏、源码切换、复制及 SVG 导出；图表跟随应用主题。
- 输入框的添加菜单提供 13 类图表提示模板，包括流程图、泳道图、时序图、状态图、甘特图与架构图。
- 新增五个独立安装的产品经理插件：`pm-toolkit`、`pm-competitor`、`pm-feedback`、`pm-pricing`、`pm-connectors`。安装方法见[插件套件说明](../pm-plugin-suite.md)。

## 定时任务与可靠性

- 任务详情可编辑项目、提示词、周期、模型和推理强度；空的模型或强度跟随应用默认值，固定选项不会改写 Pi 的全局默认值。
- 支持编辑已结束的一次性任务，以及在任务运行时修改下一次执行配置；删除确认保留在页面内。
- 修复中止请求失败后状态不能恢复、历史搜索未加载正文、项目切换与移除竞态、子代理重试边界和排队任务清理。
- 改进对话搜索、弹层键盘焦点、上下文读数、插件市场头像和安装状态，以及 MCP URL 中敏感参数的脱敏。
- 同时包含 v0.11.0 的命名子代理、worktree 隔离、独立子代理用量、悬停详情卡片及按模型请求计算的 TTFT。
