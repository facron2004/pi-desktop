# Pi Desktop v0.11.17

## 更新内容

- **修复「Could not read the update release (HTTP 403)」**。原因不是发布页坏了，而是 GitHub 的匿名 REST API 限制：每个出口 IP 每小时只有 60 次，同一网络下所有应用实例、重启和测试共用。旧版每次启动检查都会用 API 读安装包大小，几次启动就能把额度耗完，之后下载就报 403。
- 现在的更新流程把不占配额的部分拆出来：版本号读 `/releases/latest` 的网页跳转，安装包大小对公开下载地址发 `HEAD`，摘要读发布里的 `SHA256SUMS.txt`。REST API 仍然优先尝试（可拿到 GitHub 自己的 digest，并校验 draft / prerelease），只有 403 / 429 才回退到公开文件；5xx 仍然报错重试。每次启动检查消耗的 API 请求从 2 次降为 0 次。
- 回退路径不会选到 draft 或 prerelease：版本号来自 `/releases/latest` 的网页跳转，只会指向已发布的正式版本，校验方式（大小 + SHA-256 + 安装前验证）保持不变。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.17` 标签构建。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布。
