# Pi Desktop v0.10.16

本版本改进会话搜索覆盖范围、子 Agent 取消和结构化结果处理，并让会话计时样本在长会话中可靠恢复且有界保存。

## 改进

- 会话搜索不再固定截断在最新 240 个候选；在总字节预算内继续检查较旧会话。候选元数据读取使用有界并发，搜索只接受会话根目录内的文件，并在读取内容前再次验证文件。
- 子 Agent 可从任务栏和子 Agent 树停止排队或运行中的单项任务。结构化输出 schema 无效时给出明确错误，JSON 结果解析兼容单行说明和代码围栏。
- 长会话从尾部恢复时，即使可见用户消息序号发生变化，也能在时间戳唯一时恢复对应的计时样本；同一时间戳存在歧义时不猜测。
- 计时样本追加写入 indexed journal，每 128 个样本并入快照并清理 journal，避免 localStorage 索引键无限增长。
