# Pi Desktop v0.11.23

## 更新内容

- **用量条只在回合结束后出现**：输入框下方那行读数（轮数与步数、生成速度、Token、缓存命中率）在该轮结束前不再显示——运行中、以及你中途插话期间，那里只保留上下文圆环。整行高度不变，读数出现时输入框不会跳动。
- **插话直接进入当前这一轮**：运行中按 Enter 或发送键，这条消息一律作为引导插入正在进行的回合，Pi 在下一步读到，不再「排到下一轮」；设置里的「跟进处理方式（排队 / 引导）」随之移除，旧配置文件仍能正常读取。
- **问答卡是一张整体滚动的卡片**：问题与选项共用一个滚动区，细滚动条贴在卡片右缘，取消与发送固定在底部；装得下的问题不再出现内嵌滚动条；选中行改为强调色浅底与填充的序号圆点，长问题按正文排版；运行中的滚动按钮也不再压在卡片上沿。
- **切换对话不再闪一帧旧状态**：思考、工具调用与回合过程的展开状态，以及工具卡片的「完整输出」，都在该对话首帧之前读取，切到另一个会话不会先画出上一个会话的展开状态。
- **Pi 标志跟随主题**：标志的品牌色改由样式表填充，切换明暗主题时不再停在旧颜色。
- **工程**：真实渲染器验收里命令面板的按键检查会先等对话键稳定再开始，草稿落盘改名时不再误报；新增用量行时机与插话投递的单元测试。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.23` 标签构建，产物与本机 `npm run dist` 一致。
- 随包内置的 Pi 仍为 **1.6.0**；安装版可以在「关于」页把内置 Pi 单独升级到 npm 上的新版本（需要机器上已安装 npm）。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
