# Pi Desktop v0.10.10

本版本为会话运行队列设置内存边界，并降低大量会话切换、重键和淘汰时的状态管理开销。

## 改进

- 每个工作目录最多排队 64 个请求，全局最多 256 个请求；排队请求的估算载荷总量最多 32 MiB。达到上限时会明确拒绝新请求，避免积压持续占用内存。
- 会话别名通过反向索引迁移，减少重键时对全部别名的扫描。
- 非活动会话 LRU 排序不再对每个候选项重复搜索访问列表；淘汰会话时同步释放对应视图状态。
- 删除会话成功后清除该会话的流适配状态；运行状态的自动重试标记随会话迁移，并在进程启停时重置。
