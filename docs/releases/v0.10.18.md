# Pi Desktop v0.10.18

本版本优化长会话搜索和流式界面更新，并为会话索引、内联图片及本地状态文件增加边界。

## 改进

- 会话搜索查询限制为 512 个字符；长会话索引以分块方式读取和搜索，降低大索引造成的瞬时内存与主进程阻塞。
- 删除会话时会取消并等待相关索引写入结束，再清理索引文件，避免后台任务重新创建已删除的索引。
- 会话轨道预览设定长度和区块上限；轮次元数据增量更新，减少长对话每次流式渲染的全量扫描。
- 编辑器图片附件设定总量上限；文件选择、拖放和粘贴在达到限制后保留为文件引用。
- 限制 Marketplace 设置读取、定时任务文件、记忆账本条目和持久化错误文本的大小。
- 远程访问流式推送将授权状态文件检查限制为最多每 250 毫秒一次。
