# Pi Desktop v0.11.3

**发布日期**：2026-11-16  
**内置 Pi**：1.5.2（`@earendil-works/pi-coding-agent`）

---

## 同目录多会话并行

- **工作目录锁双模式**：同一项目的多个会话声明共享访问并可真正并行运行；桌面 Git 写操作（提交、暂存、还原、分支切换等）声明独占访问，等待期间阻塞重叠会话的新提示，释放后自动放行。
- **跨窗口共享锁**：锁状态落在磁盘上，多个 Pi Desktop 应用实例之间同样生效；父目录与子目录互相阻塞，兄弟目录彼此独立。
- **排队可观测**：运行状态行显示等待来源（另一会话、另一窗口或正在进行的 Git 操作）、所在文件夹与排队位置，可点击直接跳转到占用锁的会话。

## 应用提示与删除行为

- **全局浮动提示**：应用消息改为窗口右上角浮动卡片，带成功/警告/错误三态图标与关闭按钮，不再占用输入框内部布局、不再挤压输入框高度。
- **删除会话永久化**：删除会话直接移除会话文件，不再移入系统回收站；确认对话框明确说明「会话文件将被永久删除，无法恢复」。归档仍保留为可逆操作。
- **代码块头部精简**：保留语言标签，复制按钮改为纯图标，移除「询问 Pi」入口。

## 统计与计时修复

- **模型用时双重计数修复**：重开的会话此前会把本地计时样本与 Pi 记录的每条回复 `durationMs` 相加，导致 24 分钟的会话显示 48 分钟。现在 transcript 完整时以 Pi 的时长为准，本地样本仅在 transcript 缺失（如长会话尾部截断）时兜底。
- **空闲运行不再累加模型用时**：已结束或空闲的运行状态不会再把陈旧的起始时间计入模型用时。

## 会话与输入体验

- **消息编辑改为会话内回退**：编辑用户消息通过 `desktop-rewind` 扩展在当前会话树内回退到该消息之前，保留更早历史且不再新建会话；旧分支仍可从会话树访问。
- **输入区文件附件芯片**：非图片文件经添加菜单、拖放或粘贴成为附件芯片（显示文件图标与文件名），仅在发送时插入 `@"绝对路径"` 引用；旧版本草稿中的独立引用行会在加载时归一为附件。
- **市场已安装判定修复**：从官方 npm 目录安装的包即使不在内置快照中也能正确显示「已安装」；纯技能集合目录同样参与检测。

## 稳定性与性能

- **自动标题防竞争**：新一轮对话开始时中止在途的标题生成请求，避免与重命名竞争或阻塞标题队列。
- **限流重试预算提升**：Pi 默认 3 次、2/4/8 秒的退避不足以等满按分钟计的限流窗口；启动前把重试预算提升为最多 8 次、基础间隔 60 秒（用户已设更高的值不受影响）。
- **用户数据目录 ACL 修复**：启动路径改为只读检查 ACL、仅在缺失或继承开启时写入，避免无条件重置继承 ACE 在大缓存目录上阻塞启动 60–90 秒。
- **代码高亮扩展**：高亮语言表独立为共享模块，新增 PowerShell、Terraform、Zig 等别名与文件名匹配，常用语言支持同步高亮渲染路径。
