# Pi Desktop v0.11.15

## 更新内容

- **消息编辑可以撤销**。编辑一条已发送的消息时，输入框上方会出现一条「撤销」行，点击即回到编辑前的分支：被编辑掉的那段对话不丢，重新打开会话也停在你编辑的位置。发送新消息后该行自动消失——回去会丢掉那条消息，所以不再提供。
- **修复 Windows 终端句柄泄漏**。关闭一个终端标签会漏掉一个 ConPTY 原生句柄和一条工作线程：「杀进程树」成功的那一刻，退出事件恰好把清理记录移走，释放原生 PTY 的调用被永远跳过。现在关闭标签时无条件释放，长时间开着多个会话不再缓慢累积句柄。
- **标题栏只显示会话名**。移除标题旁的「子智能体」徽标——右侧任务轨已经列出同样的子任务清单，徽标只是重复，还挤占会话名空间。子智能体入口保留在任务轨与右侧「子智能体」页，目录行可直接打开子会话。
- **蜂群工作面板**。worker 逐个可停（带行内确认），派发历史与任务轨读同一份数据；面板与右侧面板的布局对齐。
- **子智能体头像**。每个子任务按批次分配固定头像（礼帽 / 单片眼镜 / 猫 / 翅膀的 Pi 标记），任务轨、子智能体页与子会话头部使用同一个。
- **侧栏「项目」列表不再折叠**。项目行是读者打开侧栏要看的树本身；「对话」列表保持可折叠，折叠箭头移到列表头右端。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.15` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
