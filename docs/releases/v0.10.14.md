# Pi Desktop v0.10.14

本版本改进模型首 token 延迟统计、子 Agent 启动兼容性，并简化非 Git 工作区的任务面板。

## 改进

- 每次模型请求从 Pi 的 `turn_start` 开始计时，到首个非空文本、思考或工具参数增量结束；空内容、排队等待、重试退避和工具间隔不计入 TTFT。
- TTFT 样本以模型请求为单位保存。旧版等待首段文本的样本会在读取时丢弃，其他兼容的单调时钟统计会保留。
- 子 Agent 无法从当前脚本路径重新启动 Pi 时，使用应用解析出的可执行文件和参数。
- 非 Git 工作区隐藏更改、提交和提交历史入口。
- 应用和任务栏使用统一的新三色 Pi 图标；更新 Windows AUMID 刷新图标缓存，同时沿用原 NSIS GUID 保持安装升级路径。
