# Pi Desktop v0.11.12

## 更新内容

本版的可执行内容与 **v0.11.11** 相同，属于重新打包发布：正在开发的「侧边对话」相关工作（托盘弹窗卡片、侧栏分组折叠）保留在开发分支 `wip/side-conversation` 上，没有进入本版。

功能清单请参考 [v0.11.11 更新说明](v0.11.11.md)，包括：

- 子智能体从「模式」变成工具：默认、目标、蜂群、插件四种工作模式都带有 `subagent` 工具，需要独立任务时直接委派；计划模式仍然只读并禁止委派。
- 目标条进入输入框：目标只保留输入框上方的一行，状态词前是按压状态着色的图标块，运行时长与阻塞原因移进「目标详情」浮层。
- 添加菜单：`+` 菜单为一行一项的列表，名称与说明同行显示，过长时省略。
- 图片附件在消息里显示为一枚固定大小的图片图标，点击仍打开原图。
- 目录租约、设置文件、会话全文搜索、定时任务与记忆自动学习的一批健壮性修复。
- 内置 Pi 升级只有在装好的 CLI 真能启动并打印目标版本时才报告 100%。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.12` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
