# Pi Desktop v0.10.8

本版本修复应用更新、工作区会话绑定和文件路径授权问题，并完善开发启动与会话界面表现。

## 修复

- 设置页检查 GitHub 最新发行版并提供下载页入口；打包版 Pi CLI 随 Pi Desktop 更新，不再尝试向 `app.asar` 安装 npm 包。
- 会话运行保持绑定到创建它的工作区；移除工作区时停止对应运行，并阻止关闭期间启动新的运行时。
- 文件定位、打开和用量统计限制在应用授权的工作区或会话目录内。
- 开发启动清除继承的 `ELECTRON_RUN_AS_NODE`；RPC smoke 脚本使用增量 UTF-8 解码，避免跨数据块字符损坏。
- 修复右侧面板最大化时会话轨道覆盖面板边缘的问题。

## 验证

- `npm run typecheck` 通过。
- `npm test`：696 项通过，2 项跳过，0 项失败。
- `npm run dist` 成功生成 Windows 通用、x64、ARM64 安装包及两个架构的解包应用目录。
- `node scripts/verify-package.cjs` 确认 x64 安装目录内归档版本为 0.10.8，主进程、渲染器与远程伴侣入口齐全。
- x64 与 ARM64 的 `app.asar` 均包含版本 0.10.8。
- 已为四个发布文件计算 SHA-256。

- `Pi.Desktop-0.10.8-x64.exe` — Windows x64 安装包
