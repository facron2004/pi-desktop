# Pi Desktop v0.11.11

## 更新内容

- **子智能体从「模式」变成工具**。默认、目标、蜂群、插件四种工作模式都带上了 `subagent` 工具，需要独立任务时直接委派，不必先切到「子智能体模式」；计划模式仍然只读并禁止委派。模式列表、`/subagent` 命令、启动器动作与已保存的模式选项一并移除，旧的子智能体模式会话重新打开时回到默认模式；保存的原始工具列表不再把受管理的 `subagent` 留在里面。
- **目标条进入输入框列**。目标条不再在会话区和输入框上方各画一次，只保留输入框上方的一行：与输入框同宽、留出清晰间隙，靠滚动条滚动也不会和输入框挤在一起。状态词前的靶心改为按状态着色的图标块，运行时长与阻塞原因移进「目标详情」浮层——从上方展开，带编辑入口，目标很长时不再挤压右侧按钮。
- **添加菜单**。`+` 菜单改为与输入框同宽的宽面板，一行一项，名称与说明同行显示，过长时省略；新增蜂群模式与插件模式入口。任务运行中相关行禁用，键盘焦点跟着当前页移动，`aria-expanded` 跟随开关状态。
- **图片附件**。用户消息里的图片不再展开成大图预览，而是固定大小的一枚图片图标，点击仍打开原图；气泡是读提示词的地方，一张 190px 的截图会把提示词挤出屏幕。Pi 写给模型的 `[Image: 原始尺寸…]` 说明行不再出现在气泡里。图片参数设置在点「停止」或清空队列时按 id 取消，不会在之后把参考图提示补发出去，草稿与附件原样留在输入框；清空队列也只把用户提示放回输入框，不会恢复这类临时命令。
- **目录租约**。读取目录租约注册表临时失败时不再当成「空注册表」或损坏文件处理，而是保留现有租约并重试释放；Git 写操作会等待正在进行的释放完成再判断能否占用，等待注册表锁的会话写入与 Git 操作排同一个先进先出队列，后来的写入不能抢先。
- **设置文件**。读取设置时的临时 I/O 错误（如文件被占用）不再被当成「内容损坏」而用默认值覆盖磁盘上的设置；保存会如实报错，磁盘上的工作区、置顶会话与语言等设置保持不变。
- **会话全文搜索**。建索引期间会话文件被删除或替换时，旧文件的命中不再出现在结果里——返回前会按文件名与文件身份复核来源仍然存在。
- **定时任务**。只有保存的运行记录与仍然存活的租约匹配时才跳过本次到期执行。先取租约、后保存运行的短暂空档，或崩溃进程留下的租约，都不会吞掉这一次执行；租约清理后调度器照常补跑。
- **记忆自动学习**。关闭自动学习会取消已经开始的启动批次；即使在这批返回前又打开开关，旧批次也不会继续写入记忆，重新打开的自动学习从新批次开始。手动「记住这次对话」不受影响。
- **内置 Pi 升级**。升级只有在装好的 CLI 真的能启动、并打印出目标版本时才报告 100%；版本不符或启动失败都会如实报错，不再出现「进度满格但 agent 还是旧的」。升级结束时维护状态在所有结果下都会释放。
- **子智能体行**。任务栏里的子智能体行改用与交付文件一致的 20px 图标块，按排队 / 运行 / 完成 / 失败着色，不再是行尾的一个圆点。

## 发布说明

- 本次发布由 GitHub Actions 从 `v0.11.11` 标签构建，产物与本机 `npm run dist` 一致。
- 应用内更新读取 `releases/latest`，请保持该 Release 不是草稿、不是预发布，否则旧版本收不到更新提示。
