# Pi Desktop v0.7.0

本版本完成 Conversation Stream V2：对话区从“聊天加工具气泡”升级为完整的 Agent 执行时间线，覆盖事件适配、流式渲染、滚动、多会话隔离与长输出性能。内置 Pi coding agent 保持 **1.4.0**。

## 主要更新

- **事件适配层**：新增 `stream-events.ts`，将真实 Pi RPC 事件归一化为带 thread/run/turn/message/tool 身份、序号与状态的 `StreamEvent`；实时流与会话回放共用同一投影。
- **组件拆分**：新增 `components/conversation/`，独立出 AssistantMessage、StreamingText、ToolResultPanel、CommandOutput、FileChangeRow、RunSummary、ErrorNotice、LogOutput。
- **工具执行**：一次调用一个节点，支持 proposed / running / ok / error / aborted；已完成节点不会被迟到或重复事件回退，未执行调用在回放和停止后仍显示 “Not run”。
- **流式与滚动**：文本按帧批量上屏；每个会话独立保存阅读位置与展开状态，空会话切换不丢失，draft 落盘时迁移；Composer 增高不会遮挡最后一条消息。
- **长输出与视觉**：工具日志按 200 行分页，工具行 34px，消息节奏 24px；运行状态使用真实工具语义，thinking 原文不渲染。
- **可靠性**：文件变更只统计成功的 edit/write；错误回答的 run 显示 Failed；重复 `message_start` 按 messageId 去重。
