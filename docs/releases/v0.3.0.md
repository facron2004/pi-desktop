# Pi Desktop v0.3.0

本次更新集中改善 Codex 风格工作台与会话信息流，并将内置 Pi coding agent 升级至 **1.4.0**。

## 主要更新

- **更安静的会话信息流**：连续工具操作汇总为活动行，思考与结果按需展开，错误详情自动展开；保留单一运行状态与真实耗时。
- **更简洁的消息操作**：鼠标悬停才显示时间及复制、编辑图标，按钮不带文字；编辑会从该消息处重开分支并恢复原文。
- **统一的桌面布局**：调整侧栏、输入框、模型与推理控件、工具面板以及深浅主题，改善窄窗口和大字号显示。
- **更多项目工具**：集中查看文件、Git 更改、任务清单、网页和图片，改进审查、差异折叠与终端交互。
- **更完整的设置**：扩充外观、系统字体、模型、个性化、插件与用量页面；从本地会话汇总 Token、费用与模型使用情况。
- **稳定性修复**：改进 Windows 项目路径去重、Git 工作区统计和差异折叠；会话搜索避免直接停止正在运行的任务；修复窗口关闭后的延迟访问。

## 下载与升级

| 文件 | 适用设备 |
| --- | --- |
| `Pi-Desktop-0.3.0-x64-setup.exe` | Windows x64 安装版 |
| `Pi-Desktop-0.3.0-arm64-setup.exe` | Windows ARM64 安装版 |
| `Pi-Desktop-0.3.0-portable-x64.zip` | Windows x64 免安装版，解压后运行 `Pi Desktop.exe` |
| `SHA256SUMS.txt` | 发布文件 SHA-256 校验值 |

升级会继续使用已有的本地设置和 Pi 会话，无需迁移。安装包不包含个人配置、凭证或会话导出。

Windows x64 发布包在独立配置目录中进行实际启动和界面验证；ARM64 发布包完成构建及包内容检查。
